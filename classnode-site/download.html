04 / 下载与安装

下载支点课堂

先确认教师电脑的系统和芯片型号，再选择安装包。

Windows

在「设置 → 系统 → 关于」查看系统类型。普通 64 位电脑选 x64，ARM 电脑选 ARM64。打开下载的 .msi，按提示安装。

macOS

在苹果菜单的「关于本机」查看芯片。Apple 芯片选 Apple Silicon，Intel 芯片选 Intel。打开 .dmg，按窗口提示安装。

选择下载渠道

GitCode 发布页 ↗ 123 云盘 ↗ 夸克网盘 ↗ 百度网盘 ↗

安装后启动支点课堂，等服务就绪后打开教师端。查看第一次开课的步骤 →
