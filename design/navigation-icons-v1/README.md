# 学习功能导航图标

两枚图标基于同一个 24×24 网格、圆角端点和线性语言设计。

- 学习单：夹板和两项作答状态，表达学生完成课堂学习任务。
- 探究空间：浏览器窗口内的圆点、方块和连接路径，表达教师制作的交互式网页；避免地球图标被理解成普通网站，也不使用偏向某一学科的实验器材。

`worksheet.svg` 与 `explore-space.svg` 使用 `currentColor`，可直接继承导航项的灰色、蓝色或紫色。项目内的实际使用由 `src/lib/navigation-icons.tsx` 提供，教师端和学生端复用同一份组件。

推荐尺寸：教师展开侧栏 18px、折叠侧栏 22px、学生顶部栏 21px。18px 时线宽 1.5，21px 时线宽 1.9。
