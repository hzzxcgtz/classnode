# 学生顶部导航图标重设计

本目录只包含设计产物，没有修改任何应用代码。

## 图标语义

- `worksheet.svg`：一张带折角的学习任务页，两项勾选状态突出“在线完成课堂任务”。
- `explore-space.svg`：网页窗口和两组可拖动控制条，表达教师制作的交互式探究网页。
- `ai-companion.svg`：两个重叠的对话气泡、三枚对话点和 AI 星芒，表达学生与智能体持续对话。

## 统一规则

三枚图标均采用 24×24 viewBox、1.8px 基准线宽、圆角端点和圆角连接。建议学生顶部导航显示为 21–24px；未选中使用 #64748B，选中分别使用蓝 #2563EB、紫 #7C3AED、青 #0E7490。

SVG 使用 `currentColor`，可以直接由导航状态控制颜色。若实现工具需要修改大小，只调整 SVG 的 width/height，不缩放或重写路径。
