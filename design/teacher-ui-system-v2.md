# ClassNode 教师端 UI 系统 v2

> 本文是教师端界面的当前视觉与交互基准。`design/classnode-design-spec-detailed/` 中的森林绿和多页面身份色方案为历史稿，不再作为实现依据。

## 1. 产品定位

教师端是课堂前、中、后持续使用的工作台。设计目标不是活泼或装饰，而是让教师在较高信息密度下快速判断、快速操作，并能长时间使用而不疲劳。

核心原则：

1. 同一个产品只有一个主操作色，不为不同模块更换主题色。
2. 先显示结论和操作，再显示解释。实现细节不进入常驻界面。
3. 颜色只承担两种职责：蓝色表示可交互，绿橙红表示状态。
4. 大面积区域使用中性表面，分类色只允许出现在图表、标签和小图标中。
5. 教师在课堂中使用的页面优先保证扫读速度，减少圆角胶囊、渐变和悬浮动画。

## 2. 设计参数

- 视觉变化：4/10。整体稳定，仅在内容结构上形成差异。
- 动效强度：2/10。只有悬停、按下、加载和状态切换反馈。
- 信息密度：7/10。适合桌面与 iPad，不做营销页式大留白。
- 圆角规则：输入框与按钮 8-10px，卡片 12px，弹窗 16px，状态胶囊使用全圆角。
- 阴影规则：默认卡片无明显投影，仅弹窗、菜单和浮层使用投影。

## 4. 页面骨架

### 全局外壳

- 桌面侧栏宽 220px，背景与内容区轻微区分。
- 内容区最大宽度 1440px，桌面内边距 32px，iPad 24px，窄屏 16px。
- 当前导航只使用一种选中方式：浅蓝底、蓝字、左侧 3px 标记。
- 页首不使用彩色大卡片。标题、说明和主操作位于同一行，下方一条分隔线。

### 列表和资产页

适用于学习单、探究空间、AI 智能体、课堂管理、头像管理。

- 顺序固定为：页首、概览或筛选、内容、分页。
- 搜索和筛选位于一个 52px 高的工具栏中。
- 卡片标题区统一使用 `#F8FAFB`，不得按模块换颜色。
- 卡片悬停只加深边框，不上浮，不出现大面积彩色阴影。
- 同一张卡片最多保留一个主操作，其余使用次级按钮或文字按钮。

### 数据页

适用于仪表盘、历史数据、课堂统计。

- KPI 使用白底、边框和深色数字，不使用整卡渐变。
- 图表可以使用多系列色，但图表外层标题、按钮和筛选仍使用主蓝色。
- 真实状态可以使用语义色。例如健康为绿，异常为红，进行中为橙。
- 数字使用等宽数字特性，避免刷新时跳动。

### 编辑和创建页

适用于创建课堂、学习单编辑、智能体接入。

- 步骤用于表达真实流程，不把普通分区包装成步骤。
- 字段标签位于输入框上方，帮助文字紧邻字段。
- 底部主操作栏可以固定，但不能遮挡正文。
- 一屏只保留一个实心主按钮。

### 实时课堂看板

- 课堂标题和核心状态固定在顶部，课堂控制按频率分组。
- 看板模式是二选一分段控件，不使用大型按钮。
- 学生筛选只显示标签、数量和必要量词。
- 口径解释、实现说明放入帮助入口或 tooltip，不作为常驻文字。
- 选中筛选使用蓝底白字；需关注只有在未选中且数量大于零时使用浅红提示。

## 5. 主要页面规则

### 仪表盘

- 第一行四个 KPI 使用同款中性卡片。
- 下方业务区块统一白底和浅灰标题栏。
- 颜色差异只留在图表数据和健康状态中。

### 学习单、探究空间、AI 智能体

- 三页共享同一网格、卡片和工具栏。
- 类型、平台和用途可以作为小标签，不改变卡片标题背景。
- 已关联、未关联、启用、停用必须同时有文字，不依赖颜色判断。

### 班级管理

- 班级切换器只负责切换上下文。
- 当前班级信息、统计和设置位于统一工作区标题栏。
- 学生列表使用表格；批量操作仅在选择后出现。

### 课堂管理

- 概览数字采用一个连续统计条，不堆叠四张独立卡片。
- 课堂卡突出标题、状态、学生数和进入课堂操作。
- 权限状态使用紧凑开关，不与主操作争夺注意力。

### 头像、课堂安全、数据管理

- 延续相同页首、工具栏、表格和弹窗规则。
- 危险操作默认使用红色文字或描边，确认后才使用实心危险按钮。

### 使用指南和关于

- 属于阅读页，可以适度放宽行距，但继续使用相同侧栏和页首。
- 不引入新的品牌色、渐变背景或另一套卡片风格。

## 6. 文案规则

1. 按钮使用动作短语，建议 2-6 个汉字。
2. 常驻控件不写括号解释，不出现实现口径和开发术语。
3. tooltip 只解释操作后果，不复述按钮文字。
4. 空状态说明下一步，不讲系统内部原因。
5. 错误信息说明发生了什么，以及用户下一步可以做什么。

示例：

- `取消所有筛选（含右边「此刻在线」那一段）` 改为按钮 `全部`，tooltip 使用 `显示全部学生`。
- `当前筛选下没有学生，请退出全屏后切换筛选条件` 改为 `没有符合条件的学生`。
- `自动获取后会填入这里，也可以手动输入` 保留在字段帮助文字，不放入按钮。

## 7. 响应式与可访问性

- 桌面按钮高 40px，触控端至少 44px。
- 输入框桌面 42px，触控端 46px。
- 图标按钮必须有 `aria-label` 和 tooltip。
- 文字与背景满足 WCAG AA。
- 键盘焦点统一使用 `rgba(70, 107, 138, .18)` 外环。
- 减少动效模式下取消位移和循环动画。
- 1024px 以下统计卡最多两列，768px 以下单列。

## 8. 实施顺序

1. 使用本规范中的令牌统一全局外壳和基础组件。
2. 统一列表页工具栏、统计条和资产卡。
3. 整理仪表盘和课堂看板的信息层级。
4. 清理内联颜色、长 tooltip 和重复局部样式。
5. 每次修改后检查桌面、iPad、窄屏以及加载、空、错误、禁用状态。
