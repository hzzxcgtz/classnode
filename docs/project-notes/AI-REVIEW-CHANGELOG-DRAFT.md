# 自动评价与班级汇总更新说明（已并入 2.1.6）

- 需要AI评价的作答统一在学生提交后自动评价，保留计分选择和每人评价次数，失败可重试；升级不触发历史批量评价。
- 同次调用保存核心反馈与结构化作答依据。教师可在学生任务的评价历史中展开“查看分析依据”；学生只看到核心评价、建议与需要时的分数。
- 教师可对未评学生逐个或分批补评，跳过已有有效结果和在途评价；取消全班重评，旧重评请求也被拒绝。
- 表达评价任务的班级分析汇总有效个人反馈与依据，不再重复发送全班图片、录音；客观练习、调查任务保留原始数据分析。混合填空保留非AI空的文字上下文，未转写语音明确不推断内容。
- 报告显示覆盖人数与证据局限，兼容无详细依据的历史评价；数据或标准变化时拦截过期报告，材料过长时分组汇总。
- 外部模板合并为5.1版通用参考模板，内置应用并支持教师自用专业学科智能体，具体规则与返回协议移入动态请求。先升级应用，再备份替换外部旧模板；仓库更新不会自动发布官网或修改外部智能体。
- 整机备份恢复、课堂可读归档保留新增依据。原有评价、附件与成绩不因升级清空。
