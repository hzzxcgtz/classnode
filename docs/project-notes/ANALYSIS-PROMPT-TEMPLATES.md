# 分析提示词模板库

教师入口仍为 ClassNode 的“AI 智能体 → 分析提示词模板”。小学、初中各含语文、数学、英语、科学、信息科技及其他学科通用，共 12 份完整模板。

模板 Markdown 存于官网 `https://www.aicls.xyz/prompt-templates/analysis/`，对应源码目录 `myportal/prompt-templates/analysis/`。官网不做模板展示页，由 ClassNode 后端读取文件，教师在应用内预览、复制和下载。详见 [远程 MD 服务与发布步骤](ANALYSIS-TEMPLATE-LIBRARY.md)。

模板 v4.4.0 对应 ClassNode 2.1.5 的统一评价：文字与教师图片可共同组成 AI 评价要求；主观文字与原始音频都可以评价；评分由每次设置决定。普通填空与表格题按学生、部分索引逐空对应，不覆盖本地自动判分。系统每次请求提供名单和机器协议，模板不写死动态 JSON。

模板包含角色、目标、学科证据边界、公共工作流、输出结构和限制；“可优化区”和“固定区”的标题只用于教师阅读，复制与下载移除这些编辑说明。教师可按长期风格调整提示词，日常任务要求在学习单内填写。班级报告、个人评价与补评分别遵守实际请求模式。

复制优先使用浏览器剪贴板，失败时使用普通局域网 HTTP 可用的兼容方式；仍被拒绝时可在“原文”手动复制。切换会取消旧请求、清空旧内容，避免复制错学科。新版模板需教师复制到外部智能体后发布，既有智能体和历史评分不会自动改变。

## v4.4.0：以每题要求为主要依据

12 份模板精简为共同的执行规则与简短的学科证据边界。每题（或每空）的 AI 评价要求中，文字和图片共同构成主要评价依据；结合任务描述理解目标。模板不再按学科额外要求修辞、语言流畅、语速、书写美观或课堂训练活动。要求缺失时仅围绕任务明确目标给出定性反馈；缺少评分依据或图文要求冲突时说明局限、不猜分。

保留学生身份、评价范围、计分开关、逐空索引、原始音频、不可用证据、评价与建议字段及动态机器协议。班级信息收集的统计和名单规则继续保留。本次生成的是官网待上传的文件；上传后还需教师将新版提示词复制到外部智能体并保存发布，已有智能体不会自动更新。
