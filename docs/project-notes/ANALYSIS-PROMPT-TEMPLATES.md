# 评分提示词模板库

入口：AI 智能体页面顶部的“提示词模板库”。接入或编辑智能体时，选择“分析”用途后，选项右侧显示简短的提示词参考位置说明。

第一批包含小学、初中的语文、数学、英语、科学、信息科技及其他学科通用，共 12 个组合。每份 MD 已包含固定输入协议、分析结构、评分边界和一个对应学科模块，可以直接复制到外部智能体的系统提示词中，无需手动拼接。教师可调整年级难度、观察重点及教学建议；每道题的满分、评分标准与运行期数据协议仍以 ClassNode 请求为准。

模板文件位于 `public/prompt-templates/analysis/`，目录元数据位于 `src/lib/analysis-prompt-templates.ts`。修改或新增模板时同步目录，并运行 `pnpm test:client`。每个学段与学科组合只对应一个完整模板。

2026-10-10：模板按扣子常用的“角色、目标、技能、工作流、输出格式、限制”结构整理。“可优化区”集中放置角色、目标、学科技能和教学偏好；“固定区”集中放置工作流、输出格式、学生对应与评分限制。班级报告只保留“整体情况、值得关注的问题、下一步怎么教”，通常 300—500 字，不点名学生、不罗列个人错误。个人建议另行逐生返回，需要评分时按系统协议附带成绩。没有机器反馈协议时使用明确的文本格式；典型问题名单通过 `<classnode-feedback>` 独立数据块按完整标签校验，班级正文链接显示可信人数，悬停、聚焦或点击显示具体姓名。所有题型的逐生建议与成绩独立保存，未开启评分也可显示；旧结果需重新生成才能补齐结构化名单与建议。模板页面标记可优化区与固定区，复制给智能体时去除这些教师编辑说明。

已配置的 Coze 智能体需由教师将新版模板复制到其系统提示词并发布，模板库更新不会自动修改外部智能体。ClassNode 每次请求的引导语也已同步新的教师分析要求；已保存的历史分析不自动重写，重新生成后才会得到新版分析。

`next build` 将 MD 复制到 `out/prompt-templates/analysis/`；桌面打包复制整个 `out/` 到内置服务的 `frontend/`。打包完整性检查逐份核对模板及模板库页面。源码分发包含 `public/`，部署后同样可用。模板查看不调用外部 AI 服务，不消耗额度。

一键复制优先使用浏览器剪贴板，失败时尝试兼容普通局域网 HTTP 的复制方式；浏览器仍拒绝时显示手动复制提示，可切到“原文”选择文本。页面也提供下载 MD。模板与当前选项绑定，切换时取消旧加载，避免复制到上一份模板。
