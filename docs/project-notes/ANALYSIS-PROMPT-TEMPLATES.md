# 分析提示词模板库

教师入口仍为 ClassNode 的“AI 智能体 → 分析提示词模板”。小学、初中各含语文、数学、英语、科学、信息科技及其他学科通用，共 12 份完整模板。

模板 Markdown 存于官网 `https://www.aicls.xyz/prompt-templates/analysis/`，对应源码目录 `myportal/prompt-templates/analysis/`。官网不做模板展示页，由 ClassNode 后端读取文件，教师在应用内预览、复制和下载。详见 [远程 MD 服务与发布步骤](ANALYSIS-TEMPLATE-LIBRARY.md)。

模板 v4.3.0 对应 ClassNode 2.1.5 的统一评价：文字与教师图片可共同组成 AI 评价要求；主观文字与原始音频都可以评价；评分由每次设置决定。普通填空与表格题按学生、部分索引逐空对应，不覆盖本地自动判分。系统每次请求提供名单和机器协议，模板不写死动态 JSON。

模板包含角色、目标、学科技能、公共工作流、输出结构和限制；“可优化区”和“固定区”的标题只用于教师阅读，复制与下载移除这些编辑说明。教师可按长期风格调整提示词，日常任务要求在学习单内填写。班级报告、个人评价与补评分别遵守实际请求模式。

复制优先使用浏览器剪贴板，失败时使用普通局域网 HTTP 可用的兼容方式；仍被拒绝时可在“原文”手动复制。切换会取消旧请求、清空旧内容，避免复制错学科。新版模板需教师复制到外部智能体后发布，既有智能体和历史评分不会自动改变。
