# 通用模板交付与兼容

模板库仅展示一份“通用教育评价与学习分析”模板，取消学段学科选择。复制与下载取同一份正文，在线查看隐藏生成注释。

universal 模板由生成脚本同步至前端参考常量、后端内置常量及 myportal/prompt-templates/analysis/universal.md。后端直接返回内置内容，不访问官网，不依赖网络发布。模板版本为 5.1.0，应用版本仍为 2.1.6。

为兼容旧安装包，原 12 个文件路径和后端模板 ID 保留，仓库中的正文统一为通用模板。旧 ID 仍使用受限 HTTPS 读取：固定官网路径、不传课堂数据或凭据、不跟随重定向、10 秒超时与 256KiB 大小限制。未上传官网前，旧客户端读取的仍可能是旧正文。

教师可用自己的智能体或经过试用的学科智能体，不必照搬模板。页面说明先备份外部配置、调整冲突规则，并以少量真实作答验证学生对应、反馈、评分及班级分析。应用不会修改外部配置。

检查：node scripts/generate-analysis-prompts.mjs --check，以及模板目录、正文提取、模板来源测试。官网文件尚未部署，外部智能体未替换。
