# 评价语音朗读

2026-10-31。

教师入口：智能体管理 → 语音朗读设置。选择已保存的扣子个人访问令牌、读取系统和自定义音色，试听后保存。默认关闭；开启后教师在放大讲评的“评价建议”页选择“朗读评价”或“朗读建议”。学生端不提供朗读入口。不新建智能体，不修改评价提示词。

令牌须有 listVoice 和 createSpeech 权限。参考官方文档：
- https://docs.coze.cn/developer_guides_list_voices
- https://docs.coze.cn/developer_guides_text_to_speech

后端固定调用扣子 HTTPS 地址，不接受客户端自定义上游地址。所有语音设置、试听和朗读接口均要求教师会话，学生令牌被拒绝。教师朗读接口仅接收当前所选评价或建议的文本，拒绝空值、错误类型和超长输入。令牌使用现有加密存储，不返回浏览器。

文本去除 Markdown 标记，按 UTF-8 字节切成不超过 1000 字节的片段，合成为 MP3 后顺序播放。未缓存的试听和教师朗读会产生扣子语音合成费用，试听持久化策略见下文。相同令牌标识、音色和内容共用本次服务进程中的有界缓存；同时相同请求合并。缓存上限 32 MiB，并发最多 4 项，进程重启或缓存淘汰后会重新合成。缓存不写入课堂备份，关闭朗读不影响原有评价和评分。

客户端只在点击后合成、播放。评价与建议共用一个播放器，支持暂停、继续和停止并标记当前段落。切换学生、切换到作答页、关闭窗口会停止音频、作废在途请求并释放临时地址。浏览器拦截异步首次播放时，提示再点一次继续朗读。iPad Safari 的实际播放体验仍需设备验证。

验证：音色列表与真实短句 MP3 合成成功；服务测试覆盖字节分段、分页、缓存及并发去重、上游失败、过期令牌；接口测试覆盖学生令牌拒绝访问、关闭状态和无效文本拒绝；学生作答流程测试确认原学生朗读路径不可用。测试不上传学生原始录音。

## 动态个人反馈表达

系统在每次个人评价、补评或班级分析所附的逐生反馈协议中，要求 reason、advice 和逐空反馈采用适合面对学生说话的短句。评价与建议可分别朗读、合读时不重复问候；不强制自我介绍或结尾套话，不添加评分维度和训练目标。班级报告正文与教师分析依据不套用学生口语要求。

称呼用名由名册中明确为个人的记录提供，整题评价开头使用一次原姓名加“同学”，不从身份标签截取姓名、猜昵称或读出学号；小组和缺失名册时直接用“你”。机器身份标签不改。维护源为 scripts/lib/analysis-prompt-content.mjs，经生成器同步到运行期策略；无需为此替换外部系统模板，不新增改写调用。仅新生成的评价采用新要求，历史文字不自动改写。

## 本地试听资源（2026-10-31 更新）

218 个系统音色的 MP3 和校验清单位于 `server/assets/voice-previews/`，约 13 MB。桌面打包复制到运行时 `assets/voice-previews/`；源码发行包随 Git 跟踪文件收录。清单记录每条实际试听文案，10 个限定语种音色采用对应语言文案。

试听按用户缓存、内置资源、上游合成的顺序读取。新增音色生成后写入 `CLASSNODE_DATA_DIR/voice-previews/<令牌标识哈希>/v1/`，开发/源码运行未设置该变量时位于 `server/voice-previews/`。此目录已忽略 Git；不复制内置资源、不写密钥，升级后保留。缓存用大小和 SHA-256 验证，临时文件写完后替换，进程内合并相同生成请求。生成失败不留可用缓存。首次未缓存音色会查询语种后生成试听；正文朗读仍是进程内缓存，不能把试听的持久化承诺用于正文朗读。

内置试听不调用合成接口；新增音色仅首次生成收费。音色列表服务不可用时回退内置音色列表。评价页仅保留评价、建议各自朗读；对话投屏可朗读单条智能体回复。播放控制独立于批注锁定层。
