# 普通填空与表格题的原始语音作答

实现日期：2026-10-27。

- 教师逐空选择手工填写、右侧选词、下方选词或语音作答。语音空有评价要求、参考要点、AI 评分开关、满分；本题可设置提交后自动评价及评价次数，沿用学习单的分析智能体。
- 原始 Ogg/Opus 音频沿用表达题上传接口与 5 分钟/2 MB 上限，不做语音转文字。学生录完可试听、重录、删除，再随整题提交。
- 继续使用 `fill-multi/v1` 的按位 `texts`，增加以稳定 blank ID 为键的 `audios`（每项为 `audio/v1`）。旧答案保持原样；音频不放入文字答案串。
- 录音、编码、上传中的 `pendingAudio` 只存在客户端。阻止提交，不写入答案，不用临时状态清除已保存作答。跨格只能有一个录音手势，上传可独立完成。
- 音频附件按“学生标签 · 第 N 空”传给现有 Coze 分析代理；完整表格与题干仍作为上下文。评分要求只下发 AI，不向学生暴露参考要点。
- 语音评分使用当前模式 `mode: audio` 配合 `gradingMode: ai`；旧文字空上的历史 `ai` 不会因此重新生效。文字空仍精确匹配。语音评分未成功前整题待评，成功后文字分与音频分一次汇总。
- AI 必须逐空返回 `parts: [{index,score,reason,advice}]`，index 从 0 开始。缺项、重复、越界等拒绝记分；静音或听不清用 null，不能按零分处理。逐空反馈按“第 N 空”保存到评价、建议中。失败评价不消耗成功评价次数。
- 教师抽屉、看板摘要、原始录音资料包及报告均能识别这些录音。普通文字和音频可共存。

验证：新增双端答案往返、附件映射、内容剥离、逐空评分协议、文字+AI合分测试；扩展真实临时数据库 HTTP 测试覆盖上传、保存、提交、评价写回、反馈读取与失败不记零分。AI 代理使用桩替代，未产生真实扣子调用。仍需在真实 iPad 上验收权限、按住/上滑取消、试听及真实智能体的逐空协议输出。

## 界面调整（2026-10-27）

语音填空采用与正文等高的单行录音/播放条，保留播放、进度滑块、当前/总时长、文字“重新录音”与删除，无额外大卡片；表达题的大播放器不变。教师右栏仅选择空位与作答方式，详细答案、候选词和语音评价要求移到下方宽区域，编辑下方表单时保留当前空位选择。转文字功能暂缓，未增加任何转写调用。

普通填空与表格题统一将整题总闸标为“是否计分：逐空评分 / 仅收集作答，不计分”。下方逐空说明分别标明“按答案评分”“AI 评分”或“不计分”；整题关闭计分时保留设置但禁用 AI 自动调用控件。点击同一道题内的评分开关时保留所选空，避免表单收起使按钮移动。
