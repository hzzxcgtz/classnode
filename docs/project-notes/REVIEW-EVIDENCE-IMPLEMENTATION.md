# 个人评价与班级汇总改造

更新时间：2026-10-30

以下按实施阶段记录；最终状态以最后阶段为准。

## 阶段一：个人评价依据（已接入）

个人评价的动态请求由 ClassNode 提供本次任务协议，额外要求返回一个 `classnode-evidence` JSON 块；外部智能体不需要预先配置此字段协议。当前班级分析与教师补评调用保持原逻辑，避免提前改变输入来源。

结构：`students: [{student, summary, criteria: [{requirement, status, evidence}], limitations}]`。status 为 met、partial、unmet、uncertain。内容只记录可观察事实及识别局限，不要求模型内部推理，不额外增加评价标准。

解析时按本次完整学生标签匹配，忽略名单外记录，重复标签不采纳；限制块大小、条目数及文本长度。依据缺失或无效不使有效的学生评分、评价与建议失败。

存储在 WorksheetAnswerReview.question 现有 JSON 快照的 `evaluationEvidence` 属性（含 version:1）中，与已有 evaluationUsage 同属本次评价元数据；不增加数据库列。评价作答快照、generation 与标准有效性检查保持原逻辑，失效结果仍只保留历史。

学生评价列表接口继续显式枚举公开字段，不返回 question 快照或 evaluationEvidence。教师分析依据展示尚未接入。课堂备份使用现有评价记录 JSON，需在后续阶段验证往返保留新属性。

## 后续阶段

1. 统一表达评价任务提交后自动评价，移除开关，兼容旧题与评价次数；升级不自动触发历史评价。
2. 教师补评复用个人评价任务，支持仅反馈任务的成功状态判断；移除全班重评的前后端入口。
3. 班级分析改用当前有效个人评价与依据，按文字预算处理；客观练习与调查题保留原始数据分析。缺依据的旧记录降级使用已有反馈，不强制重评。覆盖人数与不足显式说明。
4. 教师折叠查看分析依据、精简外部模板、同步使用指南与更新日志，核验导出/备份、历史兼容及全班队列流程。

## 已验证范围

纯函数覆盖标签匹配、重复标签、非法状态、旧格式、限长和不确定内容。接口集成用例覆盖模拟智能体返回、保存 evidence 元数据，以及学生评价接口不泄露该元数据。上述测试不调用真实外部模型；真实智能体对动态协议的遵循程度仍需验收。

## 阶段二 A：新版用途自动触发（已接入）

版本化用途中包含表达评价时，前后端均忽略废弃的 studentAiReviewEnabled 触发标记，提交即评价；编辑器不再显示自动触发开关，仍可设置评价次数。评价配置有效性比较忽略新版题目的旧开关字段，避免仅改变无效字段导致在途结果归档。兼容字段暂保留，不进行数据库批量迁移。

旧版未转换题目仍沿用原触发规则，等待阶段二 B 与教师补评、禁止全班重评接口同时迁移；当前并非整个迁移完成。将旧题显式切换为新版表达评价即可采用新规则。新版仅反馈任务与普通/表格表达空均自动评价，调查与客观题不触发。未自动评价历史作答，未修改既有评价次数与奖励。

## 阶段二 B：旧题自动触发与教师补评（已接入）

旧版明确启用 AI 评分/评价的题目也在下一次提交时自动评价，旧 studentAiReviewEnabled 字段不再控制触发或评价配置有效性。仅收集作答、客观本地判分任务不触发。未扫描或批量重评历史课堂。

教师补评可点选缺失名单中的个别学生，也可分批补齐未评学生；新客户端补评请求携带 supplement=true，同一批至多8人。请求创建独立 teacher 来源的评价快照，复用个人评价队列（并发2），同样生成并保存详细依据。跳过正在评价的作答和与当前作答、标准、上下文、智能体、奖励单位及generation匹配的成功结果。教师成功补评不计入学生自主评价成功次数。失败保留已成功结果，不更新班级报告；旧失败稿在教师补评成功后不可重新覆盖新结果。

新版题目及仅反馈任务的 only 请求直接采用新补评链路；旧客户端未版本化计分题的非覆盖补评格式暂保留，待阶段三班级报告接口迁移一并收口。regrade=true 不论是否携带only，一律拒绝，前端移除重评按钮。

班级分析按钮不再隐式发起全班补评。前端以有效评分或仅反馈任务的有效评价与建议判断完成，并排除排队中的学生，解决null分数反复补评问题。升级既不清空旧记录，也不自动消耗额度。

下一阶段仍需将表达评价任务的班级分析改为当前有效个人反馈与作答依据的文字汇总，并接入教师查看依据、外部模板精简及备份往返验收。

## 阶段三：表达评价班级文字汇总（已接入）

现行客户端的 analysisOnly=true 全班分析请求，对需要个人AI评价的任务采用文字汇总，不上传原始作品或标准图片、不携带音频附件；客观与调查任务保持原始数据链路。未升级的旧客户端原始请求格式仍兼容，后续可统一收口。

发送前逐人核对当前已提交作答、最新评价状态、作答值、generation、评价标准、上下文、智能体及奖励单位，失败、在途、过期或不匹配记录不纳入报告。历史成功评价无详细依据时降级使用reason/advice。没有评价历史的旧班级评分，仅在作品与任务均未在统计后变更、当前分数相符时采用旧反馈。没有有效记录时返回409，提示等待或补评，不暗中调用全班原始媒体重评。

报告覆盖提示由程序生成；正文与名单只能关联实际纳入记录的学生。模型返回的新个人评分和建议不会覆盖原个人结果。较长材料按24000字符预算分组，必要时逐层压缩到最终文字预算；分组失败或超长保留原报告，成功调用逐次计入使用记录。

保存前在事务内重新核对输入指纹；作答、评价或规则变化时不保存过期报告。报告保存reviewSummary元数据，后续新提交或评价完成会使报告标为需更新。新增“查看汇总方式”说明，避免把原联系表错误标成发给AI的数据。

已验证模拟真实音频作答和带标准图片的任务在汇总时images/audio均为空，缺依据降级、覆盖提示、并发评价变化导致报告拒绝替换，以及40人材料的分组不遗漏不重复。真实智能体的汇总质量与跨设备讲评仍待验收。

剩余：教师按需查看详细依据、精简外部模板、备份恢复新元数据验证及发布说明整理。

## 阶段四：教师依据、动态协议与备份验收（已接入）

教师评价历史接口仅额外返回校验、限长后的evidence对象，不暴露整个任务快照、请求标识或generation；学生评价接口仍不返回详细依据，学生无权访问教师历史接口。表达题、绘图及需要AI评价的填空/表格均可查看折叠依据，旧记录明确说明依据未提供。教师语音历史保持紧凑播放器。

模板版本5.0.0：通用外部模板只保留基础角色，12份学科模板追加可选证据边界，不再承载评分或机器协议。动态请求补齐相应规则，按个人/补评与班级用途分流，避免个人评价混入班级栏目、作答分析混入调查结构。外部系统角色优先级不能由动态内容强行覆盖，升级文档要求先备份清除冲突外部规则。远程MD校验与复制兼容旧长模板和新精简模板。

已验证：完整备份恢复后evaluationEvidence内容一致；课堂可读归档包含摘要、证据和局限；教师接口可读取，学生接口无详细依据；真实组件浏览器验证父子折叠可持续展开、390px无横向溢出、学生组件不显示教师依据。全套单元/接口测试通过，真实Coze质量仍需人工验收。

发布说明草稿见AI-REVIEW-CHANGELOG-DRAFT.md。未调整应用版本号，未提交推送，未修改外部智能体，也未上传官网模板。剩余为真实平台、真机课堂验收及确定发布版本后打包发布。
