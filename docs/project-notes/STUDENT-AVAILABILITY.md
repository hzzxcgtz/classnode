# 学生临时停用

班级名单每行提供“停用／恢复”，并可按全部、可用、已停用筛选。状态保存在 Student.disabled，默认 false；停用不删除学生，不移动分组，不改写课堂参与者、作答或历史记录。

停用后，普通身份名单及小组成员选择不再提供该学生。已有会话被撤销、学生连接退出；直接领取会话或重新连接也会检查停用状态。身份选择页通过状态事件及重连刷新名单，已打开的小组也读取最新成员列表。教师查看课堂名单仍能读取被停用学生，历史统计保持原有课堂名单口径。

恢复为手动操作，不设定自动恢复日期。恢复后重新选择姓名即可，继续使用原有课堂参与者记录；其他学生的会话不受影响。

接口：PUT /api/classes/:classId/students/:studentId/availability，教师认证必需，body 为 { disabled: boolean }；检查班级归属，不接受字符串或其他伪布尔值。

兼容升级：在旧库迁移的最前面补齐 disabled 非空默认列，避免新 Prisma 客户端在旧表读取时失败。正式启动仍沿用原有安全升级和备份流程。

验证：临时 SQLite + 真实 HTTP/Socket 测试覆盖默认值、教师权限、班级隔离、普通与组员身份选择、令牌撤销、连接退出、恢复及历史保留；旧库补列验证幂等。浏览器隔离夹具验证桌面和 390/320px 下的停用、恢复、状态筛选及身份选择显示。

名单管理的姓名检索复用身份选择页的拼音索引，支持姓名拼音首字母（不区分大小写），同时保留姓名、学号、分组与标签检索。
