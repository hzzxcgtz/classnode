# 教师按需语音转写（第一版）

## 使用

在设置 → 语音设置 → 录音转文字中选择“学生录音转文字”的扣子令牌，保存。令牌需有 `createTranscription` 权限，与朗读开启状态、音色独立。顶部总开关与令牌一起保存后生效；关闭后禁止新的识别调用，保留令牌及已保存结果，正在进行的请求不强制中断。无配置或只有令牌而没有明确开启字段时均默认关闭。开启时显示扣子积分消耗提醒，未开启时点击转写会提示设置路径。

教师查看录音时点击“转文字”，可展开/收起、复制、放大讲评与批注。适用于使用教师录音播放器的智能学伴消息、表达题、普通填空和表格语音空。学生播放器不显示转写入口。没有修改学生原始答案或AI评分。

成功结果保存在 SQLite Setting 的 `audio-transcript:` 命名空间；键包含规范录音路径及文件内容 SHA-256。刷新、服务重启后直接读库；路径或内容变化不复用。只读取缓存不发起识别；并发相同录音合并，最多同时处理两段。失败不保存成功结果，可再次点击重试。全文转写由识别服务返回，不是评价智能体推测的原话。

转写文字可进入现有持久批注浮层。录音播放独立；转写错误不影响播放。第一版没有逐字时间戳、编辑转写、全班自动转写或修改评分依据。

## 接口与安全

`/api/speech/transcription-config` GET/PUT 与 `/api/speech/transcription` POST 均挂载在现有 requireTeacher 之后。POST 只接受应用录音 OGG URL，读取前核验路径、realpath 防符号链接越界、文件大小及 OGG 文件头。不接受外部 URL。服务端令牌不返回前端；失败不泄露上游正文或本地文件路径。缓存保存在数据库，完整数据库备份可保留；尚未额外扩展单课堂资料包的转写导出。

## 官方依据（2026-11-01 核对）

- https://docs.coze.cn/developer_guides_audio_transcriptions
- https://docs.coze.cn/dev_how_to_guides_asr_tts

POST `https://api.coze.cn/v1/audio/transcriptions`，multipart `file` 参数，结果 `data.text`。接口参数表称字段为 `body`，但两份官方调用示例均使用 `file`，实现遵循调用示例。大小限制在接口页为 10MB，指南旧值为 20MB，采用更保守的 10MB。本系统录音上限5分钟，不扩展到接口文档的30分钟范围。

## 验证

服务单测覆盖 multipart、上游错误/空文本、缓存持久复用、读缓存不调用识别、同音频并发合并、内容变化失效、外部URL/路径穿越/符号链接拦截（符号链接测试在 Windows 跳过）。浏览器以模拟接口验证转写显示、全文缩放批注、刷新后复用与窄屏。前后端类型/构建、修改文件 ESLint、Safari 15 产物检查通过。未调用教师的真实令牌；真实账号权限、额度和识别效果仍需配置后手动验收。
