# 学习单统一评价设置

2026-10-27。教师可分别决定学生怎么作答、如何评价、是否计入成绩。

## 设置口径

- 选择、判断、排序、连线、归类：可自动核对答案、AI 评价或仅收集。
- 普通填空、表格题：逐空设置评价方式，同题可以混合本地核对、AI 计分、AI 反馈和仅收集。
- 表达、绘图：AI 评价或仅收集。主观表达不要求固定标准答案。
- AI 评价要求只有一个编辑区。文字和最多六张本地上传图片可分别或共同使用；图片不是学生作品。
- “计入成绩”独立于 AI 反馈，开启后须提供文字给分条件或评分量表。评价要求与图片均供教师和 AI 使用，学生版递归去除。
- “提交整题后自动评价”是题目级开关；关闭后教师发起。个人成功评价计次数，失败不扣次数。同题 AI 空合并一次调用。

## 数据与兼容

题目或 `fillBlankSettings[stableId]` 的新设置包含 `evaluationVersion: 1`、`evaluationMode: answer | ai | collect`、`evaluationScored`、`evaluationText`、`evaluationImages`。仍使用原有 JSON 数据列，无数据库结构迁移。

`worksheet-evaluation.ts` 在前后端提供相同读取规则。没有版本标记的题目保持原规则，读取不会修改配置，不恢复旧版文字 AI 空，也不新开自动调用。教师实际编辑统一要求时，把旧评价标准、参考内容、分析重点合并并加小标题。显式空文本、空图片数组优先，删除后不会回弹。

保留原 `gradingMode` 等字段作为旧代码和存储桥接；新版本以评价字段为准。作答方式切换不覆盖显式评价规则；语音不允许自动核对固定答案。

## 请求与结果

复用已有代理，不增加语音转文字调用。原始录音、学生文字、教师的文字要求及图片一起提交，明确附件编号和逐空对应关系。

内部 `AiScoringConfig.enabled` 表示需要结构化 AI 评价；`maxScore: 0` 表示只给反馈。沿用机器结果协议，反馈空的 score 为 null，计分空单独求和。反馈空不加入满分，也不阻断其他空计分。本地分只添加一次；存在待评 AI 计分空时整题保持未判分。

AI 返回 `unavailable: true` 时表示无有效内容或无法辨认，个人评价进入失败重试流程，不造分、不扣成功次数。模型未返回有效评价/建议同样不当作成功。

学生页面和评价历史区分“评价完成”和“暂无法评分”。教师看板、打印评价说明、归档字段和附件同步使用新口径。旧成绩不会因为打开编辑器或升级而重新计算。

## 验证范围

纯函数测试覆盖历史内容合并、空值删除、图片限制、混合计分和各题型无分评价。临时 SQLite + HTTP 测试验证保存、提交、自动评价、图片字节与文字共同发送、成功次数、学生读取反馈与不写入零分。

浏览器检查使用真实 QuestionCard/EvaluationSettings，验证计分选项和仅收集切换。外部智能体用测试代理替代，未进行真实扣子调用和实机 iPad 录音验收。


## 审计修复（2026-10-27）

- 新评价配置取消计分后，教师保存立即对已提交答案重算剩余本地分；无计分部分则清空当前成绩。学生保存、提交和无分评价完成也不再保留残留 AI 分。评价历史保持不变。
- 旧版整题填空在明确转换前继续按整题判分；普通输入方式、答案编辑不会创建逐空分值。转换入口显示原满分与转换后的总分，仅收集题转换后也不自动启用计分。
- 评价图片上传通过专用 reducer 动作，按题目 ID 与填空稳定 ID 合并最新图片列表。不会携带旧满分、评价文字或其他空的整份设置；已删除的空不被恢复，撤销只撤销图片追加。
- 回归覆盖真实 HTTP 取消计分、混合题移除 AI 分而保留本地分、历史评价保留、旧整题判分和异步上传期间编辑及撤销。
