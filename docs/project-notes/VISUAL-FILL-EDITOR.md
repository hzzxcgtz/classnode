# 填空题面直接编辑（2026-10-25）

教师题面中的填空显示为带编号的浅蓝横线，内部继续保留历史 `{填空域}` + `promptRuns.blank` 协议，因此旧学习单无需迁移。横线是不可拆分的编辑对象；退格、Delete、触屏删除命中时整块删除，普通文字和换行仍使用原生编辑。选中文字插空会将原文字带入该空答案，选中已有空再插入时在其后插空，不清空原答案。

点击文字横线或表格填空，会按稳定 ID 选中右侧设置面板；只有当前空显示设置，沿用已有作答方式、词池和评分逻辑，窄屏上下排列。工具栏“插入表格”选择行列后直接创建可编辑表格；网格中的普通格直接输入，选中后可设为填空或还原文字，增删行列收进“行列设置”。Excel/Word 粘贴保留，覆盖有内容的表格须确认。

`src/lib/worksheet-fill-edit.ts` 将题面前部文字空、表格空、后部文字空按 `blankSlots` 的统一阅读顺序映射答案及逐空设置。插空、删空、移动表格标记、增删行列均以 ID 对齐；写回现有位置数组，不改学生作答及服务端协议。表格的原文字保留在格子中，切回文字格时恢复。

验证包括混合题面的答案和分值保持、选中文字转换、原子删除、表格行删除，以及真实编辑器撤销/重做、保存载荷与重新加载。隔离浏览器示例使用实际 QuestionCard 与编辑组件验证，不写真实学习单。未承诺原生浏览器撤销；系统仍使用现有学习单撤销栈。


## 题面内表格与可移动对象（2026-10-26）

表格编辑体通过 React Portal 挂载到任务描述中的表格位置，取消下方单独表格区域；表格自身是不可直接改写的编辑岛，格子仍可用原生 textarea 编辑。`promptModelText` 与字符坐标遍历将整个表格岛计为历史表格标记，跳过按钮、单元格编辑控件等 DOM 文字。复制、剪切也走模型文本，避免把界面操作文案混入题干。表格操作通过浮动工具条显示，点击外部或 Escape 收起，不占题面正文空间。横线两侧及表格前后使用可点击光标落点；零宽光标字符仅存在于 DOM，读取和保存时排除，描述中的前后文字与学生渲染顺序一致。

文字填空可点击聚焦（明确选中态），提供前后光标定位、删除、前后移动、Alt+方向键移动与同任务原生拖放。`movePromptBlank` 移动完整分段，保留 ID 和文字样式，目标在其他对象内部时吸附边缘；`fillPromptPatch` 随 ID 重排答案与逐空设置。拖动取消不写入，跨任务拖放拒绝执行。表格标记被删除时同步清除表格及相应答案，仍可通过现有撤销恢复。

## 分开新建文字填空与表格填空（2026-10-26）

添加任务提供“填空题”和“表格填空题”两个入口。普通填空不再提供插表入口；表格填空的任务描述不提供插空或整题填空粘贴，作答表格在描述下方独立编辑，右侧设置所选表格空。新表格题以 `data.fillLayout: 'table'` 标识，继续使用 `fill-blank` + 末尾表格标记的既有学生作答、保存与评分协议，不新增服务端题型、不迁移历史答案。

已有纯表格题自动进入独立表格界面；同时含文字空和表格的旧题保留原混合编辑器及阅读顺序。描述编辑投影排除表格标记，保存时恢复到末尾，保留文字样式。纯逻辑测试覆盖新建/加载、旧题分类、描述往返、表格答案保留。

独立表格题的行列设置、添加一行、填空计数及表格粘贴常驻网格上方；所选格子的转换按钮单独浮动，以蓝色横线图标按钮强调“设为填空”。打开结构工具时隐藏转换浮层，避免遮挡菜单。旧混合题继续沿用原浮动结构工具。

## 单元格合并与边缘图标（2026-10-26）

独立表格题取消整行结构工具栏，在表格右缘提供插入行列、删除行列、向右/向下合并、拆分、表头开关和粘贴图标。转换填空浮层缩为 32px 高的按钮与较轻的边框阴影。

合并沿用矩形 `rows`，左上格记录 `rowSpan/colSpan`，覆盖位置仍保留空对象。文字按阅读顺序合并为多行；允许保留一个已有填空 ID，答案/评分设置仍由稳定 ID 重排。多个填空拒绝直接合并。拆分保留左上格内容；穿过合并格的增删行列需先拆分，范围外操作可正常执行。读取时拒绝越界、交叉或会遮住已有内容的坏跨度。学生渲染与教师预览使用同一跨度规则；Word 导出写入真实横向/纵向合并，覆盖位置不重复生成。

表格编辑布局改为上方等高的任务描述/填空设置两栏，下方网格横跨整行；任务标题与编辑框之间保留 14px 间距。粘贴改为 Portal 弹窗，主动粘贴、窗内格式错误提示、Tab 焦点范围、Escape 关闭并恢复图标焦点；替换已有表格时暂时关闭粘贴窗，只显示确认窗，取消后恢复已粘贴内容。

单元格浮动工具新增左/中/右、顶/中/底对齐图标，去掉行列位置文字，填空转换按钮缩为 26px 高的图标加文字。对齐写入单元格可选的 `align` / `verticalAlign`，读入时只接受白名单；合并沿用左上格设置、拆分保留设置，不改填空 ID/答案/分值。学生输入、选词槽、预览与 Word 纸卷均支持显式对齐。

表格边缘图标改为统一的格线图形：左右/上下合并分别显示水平/垂直向内箭头并附短标签；拆分显示格内新增分隔线，表头改为顶行着色、粘贴改为剪贴板表格图形。移除垂直对齐控件，浮层只保留左/中/右对齐及填空转换；已有单元格排版数据继续兼容。

## 普通填空光标检查（2026-10-26）

横线边缘的零宽落点改为行内文字高度，鼠标点击或上下移动落在父节点/原子边界时归一到真实文本节点。无修饰键的左右移动按模型字符坐标执行，Unicode 码点一次移动、填空/表格一次跨过，忽略 DOM 的零宽哨兵。选中填空对象时清除原生文本选区，仅保留对象描边，避免浏览器画出对象高度的伪光标；从对象按左右键回到正常文本光标。再次插空以当前聚焦对象的末尾作为落点。

辅助栏改为前移/后移/删除三个小图标，已有文字填空时保留固定栏高，切换选中状态不推移正文。普通填空设置栏缩至 270px，增加题面宽度。隔离浏览器实测普通文字、横线前后、相邻横线、上下跨行均为相同的 17.5px 原生 Range 高度；验证插空、删除与输入后的模型内容不含光标哨兵。

末尾回车显示修复：`pre-wrap` 的结尾换行没有可见文字行盒，渲染器在末尾换行后补一个零宽光标落点，读取/保存时仍排除哨兵。键盘 Enter 和移动端 `beforeinput` 的换行走同一个插入逻辑；输入法组合期间不处理。浏览器验证纯文字末尾首次 Enter 光标向下移动一个 24px 行高、模型仅增加一个换行，连续输入和退格正常，空题干首次 Enter 同样有效。点击正文/空白处清除填空选中，点编辑器外空白也取消；右侧设置区及浮动工具保留所选 ID。
