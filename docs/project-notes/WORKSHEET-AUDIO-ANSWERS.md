# 表达题语音作答

实现日期：2026-10-25。

## 使用范围与交互

- 表达题（含旧 open-ended 表达题）在键盘、手写、照片之外增加“语音录入”；其他题型不显示这个选项。
- 学生使用 HTTPS 安全环境与支持录音的浏览器。首次录音请求麦克风权限；HTTP 页面显示联系老师的说明，不提供无效录音操作。
- 默认按住录音、松开完成、上滑取消，也支持点按录音。录音结束生成可试听的绿色语音卡片，提供大播放按钮、时长和拖动进度，支持重录、删除。
- 松开后先保存音频草稿，沿用原来的“提交本题”及评价设置；上传期间没有可提交的音频值，失败时保留本地录音供重试。单次最长 5 分钟，Ogg/Opus 单声道 32kbps，上传上限 2MB。
- 切换学习模块、页面隐藏、窗口失焦、组件卸载或教师锁定作答时取消录音并释放麦克风。取消录音不调用 AI；内容识别不做本地静音检测。

## 数据与流程

- 题目 inputMode 为 audio；作答采用 `{ format: 'audio/v1', url, durationMs }`。服务器仅对已识别的音频格式校验本地地址与时长，不收外部音频地址。
- 学生音频经 `/api/upload/worksheet-audio` 真实 Ogg/Opus 头部校验，存入对应课堂的 worksheet 附件目录；既有附件归档、备份与清理逻辑继续按引用保留音频。
- 学生草稿/已提交内容、教师作答详情、评价历史共用播放卡片。历史值按 format 读取，后续修改题目输入方式不丢失教师查看旧录音的能力。
- 个人评价、教师补评及班级分析将音频原件上传给扣子，按音频顺序附学生标签对应表；语音使用流式接口并收集文字评价。仍沿用原有评分标准、自主评价次数、代际校验与异步队列。
- 音频只在启用既有评价或教师发起分析时外发。听不清时不应编造内容或分数。教师未开评分时不因使用语音而自动评分。
- 离线课堂资料包可播放并下载录音；Word 作答记录提供音频时长和原文件位置，音频本体在资料包中保留，不将二进制音频嵌入 Word。

## 录音组件同步修正

提取共享 Ogg 编码器加载/创建逻辑。录音会话改为收到编码器的真实 start 事件后才显示录音及启动 5 分钟计时；初始化超过 15 秒给出可重试提示。学生聊天与学习单同时使用，避免此前提前计时丢失开头声音的问题。

## 验证与边界

- 前端全量 1636 项通过；后端全量 1199 项通过、1 项跳过。含音频值往返、非法地址/时长、编辑设置→上传→保存→提交→回读→分析、混合媒体标签及原音频流式请求测试。
- 浏览器使用合成测试音频验证按住/点按录音、试听、提交后播放、重录与取消；未使用真实麦克风或学生数据。
- 多学生音频映射通过模拟扣子响应验证；尚未用实际配置的分析智能体进行多段音频识别验收。目标智能体需要具备语音理解能力，实际 iPad 录音与音频格式播放能力也需真机复测。
- 官方依据：[上传文件](https://docs.coze.cn/developer_guides_upload_files)、[HTTP 语音消息](https://docs.coze.cn/dev_how_to_guides_audio_message)、[发起对话](https://docs.coze.cn/developer_guides_chat_v3)。已复核 Ogg、audio/file_id 与流式语音接口；API 总览的 object_string 描述仍偏重图片/文件，以语音专题为实现依据。多音频同次请求的实际服务行为仍需验收，不把模拟请求结构测试作为官方能力保证。


### 教师看板录音提示

- 学习单麦克风真正开始录音后，经现有学生会话连接通知教师看板；卡片显示麦克风图标、当前任务和“正在录音”。
- 结束、取消、切换页面或卸载时结束状态；每 5 秒续期，教师端 12 秒未收到心跳则清除（每 2 秒检查），离线学生立即不显示。
- 服务端身份来自认证连接，仅向教师房间广播；不传录音内容、不落库、不改变提交进度。
