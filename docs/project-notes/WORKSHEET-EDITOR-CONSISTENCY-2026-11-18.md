# 学习单创建与编辑页面一致性检查

日期：2026-11-18

## 检查范围

检查对象为 `/teacher/worksheets/edit/` 的新建、编辑、题型选择、主题设置、学习单设置和预览相关入口。继续使用项目现有的蓝灰色样式、图标和组件，不引入新的 UI 依赖。

新增菜单有 10 个入口：选择题、判断题、填空题、排序题、连线题、归类题、表达题、评价题、图文题、绘图题。另检查已有学习单中的多选题、选择填空及旧版表达题分支；选择题的单／多选、填空的文字／选词模式仍在任务内设置。

| 题型／区域 | 检查重点 | 结果 |
| --- | --- | --- |
| 单选／多选 | 选项、答案控件、用途切换、分值、部分得分提示 | 区分圆点与方框的操作提示；收集模式隐藏答案设置 |
| 判断 | 正确答案、用途、切回练习后的原答案 | 修复收集模式仍显示答案的问题 |
| 填空／选择填空 | 填空选择、文字／右侧选词／下方选词／语音、逐空计分、答案组合 | 统一表单尺寸；精简未选填空时的重复提示；组合操作复用兼容 ID 生成方式 |
| 表格填空 | 表格插入、单元格编辑、插入行、内容保留 | 验证通过，表格宽度由内部滚动承接 |
| 排序 | 学生顺序、正确顺序、打乱操作、收集模式 | 收集时隐藏正确顺序；统一操作名称，切回保留答案 |
| 连线 | 左／右项、配对、收集模式 | 添加按钮名称统一；收集模式标题不再宣称设置正确配对 |
| 归类 | 条目、分类框、删除提示和空状态 | 统一“添加分类框”和未填写／未命名提示 |
| 表达／旧版表达 | 四种作答方式、个人评价、调查收集、观点提炼 | 语音统一称为“语音作答”；个人评价说明不再误用填空专属措辞 |
| 评价 | 图标上限、分组维度、文字感想、字数、观点提炼 | 复用公共标签和控件尺度；观点提炼说明与表达题同源 |
| 图文 | 底图、控件、评价依据、样式设置、删除 | 属性控件尺寸统一；底图移除改用系统确认框 |
| 绘图 | 四种工具、图片／教师底图、初始图、作答方式 | 移除影响题头与主题设置的旧试版样式；移除操作改用系统确认框 |
| 新建／主题／设置 | 新建与编辑身份、必填／选填、年级学科、保存、窄屏 | 标题区统一；新建面包屑准确显示；修复窄屏统计溢出 |
| 公共辅助工具 | 格式工具、链接图标选择、公式弹窗、确认框 | 统一“粘贴”用词；手机格式按钮扩大点击区；确认框支持焦点约束和 Esc 取消 |

## 本轮统一规则

- 教师端使用正式题型名称；学生端别称及内部协议不变。
- 用途仍为“练习判分／表达评价／调查收集”，输入方式独立设置。
- 普通表单输入和下拉框使用 44px 高度、8px 圆角；手机输入字号为 16px，避免聚焦自动缩放。
- 题头统一显示小题编号、题型和状态；手机状态另起一行，避免题型文字竖排。
- 同类必填／选填提示使用 `WorksheetFieldTag`。
- 评价说明、观点提炼说明和示例用语集中或复用，不把某一学科、某种输入方式的要求误用于其他题型。
- 收集模式不显示正确答案设置，不删除既有答案。切回练习后继续使用原设置。
- 主题标题和操作不随当前题型改变。绘图的专属画板设置继续保留。
- 删除／移除等确认使用系统弹窗，取消优先获得焦点，Tab 保留在弹窗内，Esc 可取消。

## 验证记录

- 320、390、768、1440px 下，13 个编辑分支和设置弹窗共 56 个视图：无页面横向溢出、无浏览器运行错误。
- 手机与电脑实际页面组件交互：六种客观题用途切换、已有答案保留、填空模式及答案组合、四种表达方式、评价感想开关和字数、图文底图确认／取消、四种绘图工具、公共设置、链接／公式弹窗。
- 新建流程：设置年级学科、保存载荷、首次保存后编辑状态切换、全部 10 个题型入口添加、表格创建和插入行保留原内容。
- 学生端预览：整页／翻页查看，以及横屏／竖屏切换。
- 答案组合新增额外验证 `crypto.randomUUID` 不可用的环境。
- 1730 项前端测试、ESLint、TypeScript 检查和 Next.js 生产静态构建通过。

浏览器交互使用真实页面组件与模拟接口，不写入真实学习单、不调用实际 AI 服务。测试截图与过程日志位于 `.dev/worksheet-editor-consistency/`。生产构建在独立临时目录执行，不影响正在运行的开发服务。
