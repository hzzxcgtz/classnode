# 独立评价题

“添加任务”提供评价题（`rating`）。默认星级上限为 3，可调整为 1–5；支持 1–60 个具备稳定 ID 的评价维度（最多三级，可仅保留一个维度），以及可开关的文字感想、自定义提示和观点提炼要求。评价图标跟随学习单奖励形式。所有界面使用通用表述。

评价题用途固定为调查收集，不提供标准答案、个人 AI 评价或计分。星星是参与者的意见，不是学习单奖励。初始不选星，再点当前星级可取消；允许保存部分维度的草稿，提交时必须完成所有末级维度的评价，分组标题不参与校验。文字感想开启后必填，可设置最少字数（默认 1），空格与换行不计入字数；不足要求时可保存草稿，提交由前后端同时校验。关闭文字感想后仍须完成所有末级维度的评星。

作答使用 `rating/v1`，保存各维度星级、星级上限及文字。当前题目已删除的维度、非法星级、上限不符的旧星级不进入当前统计；关闭文字感想后不提交隐藏文字。已有非空作答（含草稿）后，保存接口以事务保护评价上限、末级维度集合和评价题本身：会隐藏旧结果的改动返回 409，且不写入同次请求的其他字段。可继续修改名称、说明、格式及不改变末级集合的分组结构；需调整量表时可复制学习单，或先导出并清空原作答。旧数据若因早期修改而上限不匹配，可恢复到所有存量作答一致的上限，不自动换算或重写星级。

作答区采用维度与图标对齐的表格，支持鼠标悬浮与键盘焦点预览；触屏点击完成选择。结果页逐维度显示实际评价人数、各星级分布和平均值。未评价不算零星，草稿不计入分布。原答和 Word 作答记录保留可读的维度、星级及文字；教师参考学习单导出提供空星与文字作答区。

教师可使用学习单配置的分析智能体发起整体分析；仅汇总意见，不评分或排名。开启文字感想后可生成观点云，观点依据仅来自文字，不从星级或题干推断；单人观点也保留；按提及人数去重排序，观点云显示前10条，全部观点列表可查看其他观点及原始作答。不判断观点好坏。未调用真实外部智能体验证输出质量。

验证：新增前后端行为测试覆盖默认值、保存回填、部分评价、非法输入、统计分母、配置校验、分析语义和导出文本；现有题型清单对拍与抽屉呈现测试也登记了新题型。浏览器隔离预览验证实际编辑器与作答组件的交互和窄屏布局。


评价题说明使用较小正文；表格评价列按图标数量分配紧凑宽度，留出维度说明空间。图标为 26px，点击区域仍保持至少 44px。评价题标题栏与任务描述间保留间距和分隔线。

维度名称及文字提示使用已有 PromptEditor 的基本格式模式，支持局部加粗、斜体、下划线、着重号和文字颜色。格式以字符区间保存于维度 `runs` 和 `commentPromptRuns`，不存 HTML；作答预览使用同一 PromptText 渲染，分析与统计继续读取纯文本。任务描述沿用完整格式工具栏。


层级维度使用可选的 `parentId`，保留原有平铺配置和 `rating/v1` 作答格式。编辑器通过“添加子维度”创建二、三级项目，父级只作分组，末级独立评价，不合并分数或设置权重。删除分组前先删除子维度。各分支可以停留在不同层级；读入时容错处理断链、循环、超三级，保存时拒绝这些配置。父级残留评价不进入当前统计；摘要、整体分析和导出作答使用完整维度路径，纸质学习单按层级缩进且仅末级显示空星。

手机作答在 560px 以下改为上下排列：维度说明在上，评价图标在下；一级、二级分组标题与末级缩进区分，五档图标仍保持 44px 点击区域。浏览器模拟 320/375/390/430/768px 验证无页面横向溢出、分组不可评价、触摸选档、必填文字、提交保存及刷新回填；375px 编辑器也验证无横向溢出并可添加子维度。隔离预览使用测试数据，未修改现有课堂的维度。

维度编辑区共用一条基本格式工具栏：桌面端固定在维度区顶部，标明当前编辑项；手机端仅在当前维度旁显示。通过 PromptEditor 的 toolbarTarget 把原工具栏移至共享容器，保持选区、输入法、颜色设置与撤销逻辑。层级编号使用 1、1.1、1.1.1；分组标题与末级评价数量分别统计，行末保留新增子维度与删除操作。

新增维度复用编辑器的兼容 ID 生成逻辑，在局域网 HTTP 等不支持 crypto.randomUUID 的环境中也可新增顶级、二级及三级维度。
