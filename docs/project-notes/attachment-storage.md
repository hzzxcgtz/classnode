# 附件存储（2.1.3 起）

学生的新上传文件由已认证的课堂会话决定目录，客户端不能指定文件系统路径：

- `uploads/classrooms/<classroomId>/worksheet/`：学习单照片和绘图快照。
- `uploads/classrooms/<classroomId>/chat/`：智能学伴对话附件。
- `uploads/chat/`：旧版附件，以及教师编辑学习单时上传的公共配图。
- `uploads/.image-owners/`：服务端使用的图片上传归属记录，不作为网页附件公开。

文件继续使用唯一编号。数据库记录原始 URL 与学生、题目的关联，不建立学生长期文件夹。

## 兼容与清理

旧附件不搬迁、不改写数据库中的 URL。读图、旋转、AI 图片处理、Word 和课堂资料包同时接受新旧路径。不要仅凭课堂目录删除文件；清理时会检查所有消息、学习单、作答和评价历史的引用，并保留 24 小时宽限期。

完整 `.classbak` 备份包含新课堂目录及归属记录。附件专用 `.classchat` 备份包含 `chat/` 和 `classrooms/`，导入仍兼容旧版仅含 `chat/` 或平铺文件的附件包。旧数据库和旧版完整备份也继续按原有升级流程恢复。新版目录的备份应使用 2.1.3 或更高版本恢复，不建议降级恢复到旧程序。

教师公共配图可能被多堂课堂或多份学习单引用，因此不归入某一堂课堂。旧文件虽仍集中存放，导出单堂课堂时仍只按该课堂的记录收集附件。
