# 作答分析改造的验收样例

本页用于新版模板 v4.1.0 的人工教学质量核验。自动测试验证数据传递、模式、评分与报告保留；下面的生成质量仍需在教师实际配置的模型上对照检查，不能用接口成功替代。

## 设置与预期

| 样例 | 设置与模拟作答 | 应看到的分析 | 不应出现 |
| --- | --- | --- | --- |
| 三年级小习作 | 要求写一件课间小事；标准为写清经过、用一个动作或对话写具体。参考写跳绳，学生写捡树叶；分析重点是细节，不重点评价修辞。 | 用学生原句指出细节与可修改处，认可不同选材。 | 要求照参考事件或套用成人范文；因没有比喻而判不达标。 |
| 数学不同解法 | 用两种有效方法解释相同数量关系，标准要求说明依据。 | 分别说明方法及其成立条件。 | 只承认参考解法；没有过程却补写学生的思考。 |
| 数学作图 | 学生上传近似等腰三角形照片，没有长度标注。 | 区分可见结构与无法确认的精确性质，建议补标或核验。 | 凭外观断言精确等长、角度数值或尺规操作正确。 |
| 活动偏好调查 | 选择题用途为无标准答案，收集信息；选项为阅读、运动、实验；分析重点是活动安排。 | 选择分布、理由、实施约束和组织建议。 | 正确率、偏好高低排名、少数选择需要纠正。 |
| 开放探究 | 表达题无参考、无标准、关闭评分。学生提出多种校园观察计划。 | 思路差异、依据、可行性、后续追问，不要求统一方案。 | 编造唯一答案、评分或按达标率排序。 |
| 有标准不评分 | 表达题写实验方案，填写控制变量的评价标准，关闭 AI 评分。 | 围绕标准给出定性反馈和改进方向。 | 因填写标准就输出分数。 |
| 材料不足 | 模糊照片、截断文字或只有最终选项。 | 说明证据边界，提出补充材料或验证追问。 | 编造原句、操作过程、原因或作品归属。 |

## 操作核验

1. 新建题目只显示表达题入口；文字、手写、照片方式均可使用。
2. 参考作答、评价标准和分析重点都有持续可见的说明；关闭评分时评价依据仍可填写。
3. 开启评分但无评价标准时，保存应提示补充标准；标准图片也可作为依据，参考作答不强制。
4. 旧开放题保留题目 ID 和作答方式，编辑为表达题，默认关闭评分；已有表达题设置保持原样。
5. 修改分析重点或所属任务说明后，旧报告保留并提示更新；重算统计不能清除该提示，重新生成报告后消失。
6. 检查停止、补评、重评、清除报告和主观题评分功能；客观题不提供清除评分操作。
7. 外部平台提示词先备份，再替换新版；替换不会自动重评历史作答。

## 模板维护

公共教学规则维护于 `scripts/lib/analysis-prompt-content.mjs`，12 份学科与学段的具体评价方法分别维护于 `scripts/lib/analysis-subject-guides.mjs`，运行 `node scripts/generate-analysis-prompts.mjs` 同步通用模板、12 份学科模板、运行期指引和升级说明；使用 `--check` 检查同步。不要分别手工修改生成文件。

## 学习单的适用对象

年级与学科只在学习单设置中填写，不扩展班级、课堂或资源管理页面。支持小学一至六年级、初中七至九年级；学段由年级自动确定。创建和编辑保存时需选择两项，旧学习单不自动推测、不批量补写。API 仍兼容完全未提供这两项的旧客户端；显式填写时必须有效。

验证设置保存、详情回读、复制与草稿恢复后信息一致；分析发送明确的适用对象。模板建议不自动更换智能体或外部平台配置。修改适用对象后，旧报告保留并提示重新分析，不自动重评或清除成绩。
