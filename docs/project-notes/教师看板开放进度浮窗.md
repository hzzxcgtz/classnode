# 教师看板开放进度浮窗

浮窗固定在看板右侧中间，默认收起为窄条。仅显示采用「手动逐题开放」且包含可作答题目的学习单；多份学习单可切换。点击题目名称进入全班作答查看，只有开放或收回按钮会改变学生端权限。

- 手动开放：初始没有开放题目，可以逐题开放或收回，也可按顺序开放下一道尚未开放的题目。收回只隐藏题目，保留所有已交作答。
- 全部开放：不进入浮窗，学生可看到全部题目。
- 按任务或小题分步：不进入浮窗，按学生个人提交进度自动解锁，不支持教师通过此浮窗提前开放。

看板菜单的「逐题开放」入口展开同一个浮窗。浮窗可向右收起或按 Escape 收起；展开时列表独立滚动，查看作答与发布题目是两个独立操作。

开放状态复用课堂的 worksheetOpen，沿用现有 API、广播、快照与失败回滚，无需数据库迁移。前端可见性和后端作答写入闸门仅在手动模式读取此清单；开放式和分步模式忽略此清单。

验证覆盖：浮窗只列出手动模式的非空学习单，按原题序逐题列出，跳题开放只计该题，已删除题目的残留 ID 不计入开放数量；分步模式仍遵循学生自动解锁规则。界面预览使用内存模拟数据，核对收起展开、查看和发布分离及滚动固定位置。
