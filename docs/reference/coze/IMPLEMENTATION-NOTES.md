# 实施约束与文档差异

核对日期：2026-10-23。以下是阅读全文后需要带入开发的注意点。文档编号对应 [逐页记录](READING-LOG.md)，不是平台版本号。

## 必须分开的协议与配置

| 场景 | 依据 | 开发影响 |
| --- | --- | --- |
| 低代码与 AI 编程 | 83、89 | AI 编程文件输入用 `upload_file` URL，不能套低代码文件 API；两套 Web SDK 也不同。 |
| 智能体与工作流 | 82、83 | 智能体有嵌套 prompt、会话和项目 ID；工作流业务入参由动态 schema 定义。 |
| 部署 API 与 Web SDK 鉴权 | 82、83、89 | 部署接口用项目 API Token；SDK 文档列出 PAT/OAuth/SAT，不应直接互换令牌。 |
| 编程模型与业务模型 | 01、52、90、91 | 前者生成代码，后者在应用运行时推理，配置位置与计费来源不同。 |
| 编程技能与对话技能 | 65—70 | 辅助开发的技能不代表部署产物拥有同一技能；开发的技能需打包供扣子对话使用。 |
| 多人、多会话、多分支 | 72—74 | 同一协作对话有序执行；多会话共享代码；多分支独立 Worktree，但仍共享沙箱容量。 |

## API 对接速记

### 工作流

来源：[82 工作流 API](sources/dev_how_to_guides_call_a_deployed_workflow_through_api.md)。

- 短任务同步接口 `/run`，文档建议不超过 300 秒；流式建议不超过 900 秒；异步最长默认 24 小时，以返回的 `deadline` 为准。
- `/graph_parameter` 返回 `input_schema/output_schema`，用于生成与校验调用参数，不用于查询任务状态。
- 状态查询 `/task/{task_id}`；工作流示例的 `result` 为对象，智能体示例则是字符串，不应统一假定结构。
- 调试模式请求头 `x-workflow-stream-mode: debug` 可获得节点开始与结束事件。
- 流式路径：同页接口表写 `/run/stream`，curl 与排障段写 `/stream_run`。事件示例为 `workflow_end`，字段表却使用 `done`。这些差异尚未实测，不应凭笔记选定唯一路径或终止事件。
- 异步任务可能因重部署、回收或资源过载失败。若任务可能发消息或写数据，重提交前应按业务设计去重，不能仅因 pending 就盲目重试。这是工程建议。

### 智能体

来源：[83 智能体 API](sources/dev_how_to_guides_qeesmmos.md)。

- `/stream_run` 的 SSE 需要按事件帧增量解码，再读取 JSON `type`，不能假设每次网络 chunk 等于一条事件。
- 拼接 `content.answer` 后仍须检查 `content.message_end` 中状态；`answer.finish` 不等于整个调用成功结束。
- `session_id` 关联多轮会话；ClassNode 应设计学生与课堂之间的会话隔离。
- 文档 `project_id` 示例超出 JavaScript 安全整数范围。现有项目代码已考虑该问题，后续修改应检查精确序列化和部署域名路由，不能先转为 Number。
- 项目 API Token 文档写长期有效、每项目最多 10 个；FAQ 写重部署后仍有效。删除令牌与更换部署是不同操作。

### Web SDK

来源：[89 AI 编程 Web SDK](sources/developer_guides_vibe_coding_websdk.md)。

- npm 包 `@coze/web-sdk`，JS 入口 `/js`、React 入口 `/react`；也支持 CDN 与 Iframe。
- `refreshToken` 支持同步字符串或 Promise；`token` 优先级更高。生产宜由后端签发短期授权，文档建议 JWT 的 connector 范围限制为 `2001`。
- 需要 `convertFileType/uploadFileToStorage/getMetadata(VibeProject)/run(VibeProject)` 权限。
- Iframe 消息校验 SDK origin，发消息时明确目标 origin；销毁组件释放实例与监听。这是将文档用于项目时的实现要求。
- 文档出现 `destory()` 标题与 `destroy()` 示例不一致，且 Iframe 操作段缺少完整标签示例；实施时核对实际包的类型定义与版本，不复制拼写错误。

## 数据、身份与文件

- 数据库是 PostgreSQL；ClassNode 当前 SQLite 与启动时 raw SQL 迁移不能自动视为兼容（53）。
- 开发回滚可选恢复开发数据库；生产版本回滚保留当前生产 Schema 和数据，却恢复历史环境变量（41、53、84）。迁移需兼容代码回退。
- 生产对象存储只自动同步 `coze_knowledge_base`，而非 assets 和所有桶对象。长期记录 URI，通过签名链接临时访问（54、55）。
- 上传限制分别为对话附件 20 MB、部署请求 16 MB、对象存储 200 MB。若分片上传，需在应用两端实现，不能仅修改前端限制（03、55）。
- 身份认证限 Web/移动应用，基于 Supabase，默认RLS、环境用户隔离；应用身份认证不同于企业登录扣子平台的 SSO（28、58）。
- 存储 SDK 的 `file_exists` 对部分非404错误也返回 False，业务中不能直接把 False 视为确证删除；应根据错误日志排查（56）。
- SDK 构造函数与“端点配置”段对参数/环境变量优先级叙述不同，实际接入时核对安装版本（56）。

## 权限与操作范围

- 企业、组织、工作空间、项目所有者和协作者是不同权限层级（09—34、59—60、72）。缺少入口也可能是功能或资源可见性限制，并非登录失败。
- 外部连接在空间共享；组织禁用不一定撤销已有连接，影响范围应查关联项目（43—51）。
- 完整项目分享可能暴露对话、源码及环境变量；产物分享和添加协作者不是同一操作（64、72）。
- 将个人空间迁入企业、删除空间/组织、恢复数据库、停止部署会改变资源状态；本次阅读没有执行这些操作。
- 停用域名不等于停止部署，设置主域名不等于关闭其他访问入口（85、88）。

## 成本判断

来源：90—93。数值仅作为2026-10-23快照，报价时重新核查。

- 编程任务、运行时集成、托管与Trace是不同计费项；不收编程任务费不等于调用和部署免费。
- 自定义编程模型免该项编程任务费，但模型商自身费用、集成及部署成本仍可能存在。
- 托管专题按算力CU秒及GiB出流量、每天结算；技能发布不收托管费。不要把GB与GiB混算。
- Trace按GB×保留天数计算，只收费线上上报；开发调试免费。默认上报开关、时长按空间管理。
- 预算超额可配置402暂停或仅通知；429为请求限流，503为暂停服务，404可能是停止部署。需要结合上下文排障（75、85）。
