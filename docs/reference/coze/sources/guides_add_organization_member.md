创建组织后，你可以将企业成员加入对应的组织。团队高阶版、团队旗舰版、企业标准版无需执行该操作，用户加入企业时会自动加入默认组织。

:::tip 说明
* **套餐限制**：团队尊享版、企业旗舰版
* **角色限制**：默认情况下，组织超级管理员或管理员可操作。
* **访问控制**：在团队版和企业版中，企业超级管理员可以通过****功能访问控制****，控制功能的可见范围。如果你未看到预期的功能，请联系企业超级管理员确认。更多信息，请参考[功能访问控制](/guides_team_config#hnd1HfjfQ)。
:::

## 前提条件 {#f384aa11}

* 已将成员添加至对应企业，具体操作请参见[创建成员](/guides/create_member)。
* 已创建对应的组织，具体操作请参见[操作步骤](/guides/manage_organization#27857f3e)。

## 邀请用户加入组织 {#2193f6e9}

用户加入企业时将自动加入默认组织。**组织超级管理员和管理员**可以邀请员工（子用户）和外部成员（访客）加入对应的组织。成员加入对应组织后，其在默认组织中不会被删除。

1. 在[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)左下角单击个人头像，选择企业账号，然后单击对应组织的**设置**图标。
   ![Image=298x234](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7af50f48a2ba4d71ab07e7c5ec455605~tplv-goo7wpa0wc-topic.webp)
2. 在**企业组织管理**页面的顶部选择**组织成员管理**。
   ::::tabs
   @tab 单个添加
   1. 在**组织成员管理**页面，单击 **+成员**。
   2. 在搜索框中输入用户名、用户昵称或火山成员名搜索对应的企业员工或访客，选中成员，设置其身份，然后单击**确认**。
      获取用户名、昵称、成员名的步骤，请参考[如何获取用户名称？](/guides/create_member#12feca48)。
      ![Image=496x248](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fd318426934644e183d61b689ee2ec0f~tplv-goo7wpa0wc-topic.webp)
   
   @tab 分享链接邀请加入
   当企业成员数量较多，逐个添加工作量较大时，组织超级管理员或管理员可以通过分享链接，邀请企业成员加入组织。
   
   1. 在**组织成员管理**页签中，单击**分享**图标。
      ![Image=444x169](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/460147fd8b9941e599781fb2704ad349~tplv-goo7wpa0wc-topic.webp)
   2. 成员访问对应的邀请链接，申请加入组织。
   3. 组织超级管理员或管理员在**组织成员管理**的**申请管理**页面，通过成员的加入申请。
      ![Image=578x147](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/bc77b6b2263e4d7bac03b698f1520f64~tplv-goo7wpa0wc-topic.webp)
   ::::
