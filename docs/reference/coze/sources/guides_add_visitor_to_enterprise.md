访客是企业的外部用户，通常在加入企业前已自行注册了扣子账号。企业超级管理员或管理员可以将外部用户（访客）加入到企业中，以便协同开发和资源共享。团队版和企业版均支持添加访客，访客加入后会占用席位。

:::tip 说明
* **角色限制**：默认情况下，企业超级管理员或管理员可以操作。
* **访问控制**：在团队版和企业版中，企业超级管理员可以通过**功能访问控制​**，控制功能的可见范围。如果你未看到预期的功能，请联系企业超级管理员确认。更多信息，请参考[功能访问控制](/guides_team_config#hnd1HfjfQ)。
:::

## 费用说明 {#99bd94f0}

访客在企业中使用工作空间内的资源时，均由订阅套餐的购买者（即超级管理员）支付，但在商店、企业商店和模板中消耗的积分，则抵扣个人版套餐的积分。

## 设置允许访客加入企业团队 {#af39e400}

1. 企业超级管理员或管理员登录[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)。
2. 在左下角单击个人头像，选择**企业账号**> **企业管理**。
   ![Image=275x219](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e7a3158527f44332bcc6076a31e0fa4c~tplv-goo7wpa0wc-topic.webp)
3. 在左侧导航栏选择**企业成员管理**，在顶部选择**成员权限**页签，关闭**禁止访客加入企业**右侧的开关，禁止访客加入企业。
   ![Image=554x166](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9e9b6aef28c64b03adc55dd1330a01f7~tplv-goo7wpa0wc-topic.webp)   


## 添加团队访客 {#hEMF27DcS}

**团队超级管理员**可以主动添加访客，也可以通过链接或二维码邀请访客加入团队。访客加入后会自动进入默认组织，管理员可以为其分配工作空间。

::::tabs
@tab 输入账号邀请加入
直接向访客发送邀请，访客同意后立即加入企业。

1. **超级管理员**登录[管理后台](https://admin.coze.cn/)。
2. 在**企业成员管理 > 成员列表**页面中，单击**邀请 > 邀请访客**。
3. 在**输入账号邀请加入**页签中，在搜索框中输入访客的扣子用户名或用户昵称。
   查看用户名、昵称的步骤，请参考[如何获取用户名称？](/guides/create_member#12feca48)。
   你也可以单击批量导入，下载导入模板，根据要求上传名单，批量邀请多位访客。
4. 选择要邀请的访客，单击**添加访客**。

@tab 分享邀请链接
分享二维码或邀请链接，访客扫码或打开链接后可申请加入企业。

1. **超级管理员**登录[团队管理后台](https://admin.coze.cn/)。
2. 在**企业成员管理 > 成员列表**页面中，单击**邀请 > 添加成员**。
3. 选择**分享链接邀请加入**。
4. 保存二维码，或复制分享链接，通过其他通讯工具将其发送给成员。
   * 超管可重置链接，重置后，之前生成的分享链接将全部失效。
   * 链接和二维码默认永久有效，也可以按需修改为 7 天或 30 天，失效后超管需要再次获取链接和二维码。
5. 成员扫码或打开链接，单击**申请加入**。
6. 管理员登录[团队管理后台](https://admin.coze.cn/)，打开**企业成员管理 >  邀请管理**页面，通过申请。
::::

## 添加企业访客 {#7b057bb2}

::::tabs
@tab 输入账号邀请加入
直接向访客发送邀请，访客同意后立即加入企业。

1. **超级管理员**登录[管理后台](https://admin.coze.cn/)。
2. 在**企业成员管理 > 成员列表**页面，单击**+成员**。
3. 在搜索框中输入访客的扣子用户名或用户昵称。
4. 在**外部访客**区域中找到并选择要邀请的访客，单击**确认**。
   查看用户名、昵称的步骤，请参考[如何获取用户名称？](/guides/create_member#12feca48)。
5. 访客确认接受邀请。
   被邀请加入企业的访客，会收到一条来自扣子团队的邀请消息。访客单击对应消息中的链接，根据页面提示单击**加入**，即可正式加入企业组织。

@tab 分享邀请链接
分享二维码或邀请链接，成员扫码或打开链接后可申请加入企业。该方式创建成员时，成员可自行设置账号密码。

1. 在左侧导航栏选择**企业成员管理**，在**成员列表**页签中，单击**分享**图标，通过分享链接，邀请访客加入企业。
   ![Image=627x235](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a778396f2c95498c845f1573a104c67a~tplv-goo7wpa0wc-topic.webp)
2. 访客访问对应的邀请链接，申请加入企业。
3. 企业超级管理员或管理员在**企业成员管理**的**申请管理**页面，通过访客的加入申请。
::::

## 常见问题 {#27108e45}

### 访客如何登录企业或团队？ {#hfcQqRwEm}

已加入企业或团队的访客，根据用户名和密码登录扣子后，在页面左下角单击头像，可以由个人版切换到企业版或团队版，也可以在多个企业团队之间切换。
