扣子提供企业版和团队版两种多人套餐。购买对应的套餐并创建企业后，企业超级管理员可以创建成员，系统会自动激活成员账号，并将成员添加到企业中，共享企业中的高级权益与海量资源。

成员是企业的内部员工，可以使用对应订阅套餐的全部权益。

:::tip 说明
在团队版和企业版中，企业超级管理员可以通过**功能访问控制​**，控制功能的可见范围。如果你未看到预期的功能，请联系企业超级管理员确认。更多信息，请参考[功能访问控制](/guides_team_config#hnd1HfjfQ)。
:::

## 前提条件 {#066322c5}

* 已创建企业。具体操作，请参考[创建企业](/guides/create_team_and_enterprise)。
* 已购买席位。可创建的成员数由你企业超管购买的席位数决定。具体操作，请参考[套餐席位](/coze_pro/team_plan#804ac758)。

## 费用说明 {#f841ca62}

每个成员占用一个席位，不同套餐的席位单价不同，详情请参考[套餐席位](/coze_pro/team_plan#804ac758)、[变更企业版](/coze_pro/enterprise_plan#ef00b890)。

## 团队版成员 {#5f632e39}

**团队超级管理员**可以主动添加成员，也可以通过链接或二维码邀请成员加入团队。成员加入后会自动进入默认组织，管理员可以为其分配工作空间。

::::tabs
@tab 直接添加成员
创建成员登录账号，系统将通过邮箱发送账号信息给对方。

1. **超级管理员**登录[管理后台](https://admin.coze.cn/)。
2. 在**企业成员管理 > 成员列表**页面中，单击**邀请 > 邀请成员**。
3. 在**为成员设置账号密码**页签中，单击**创建账号**。
   填写成员的登录名、昵称和邮箱，支持批量添加多个成员。其中：
   * 邮箱须填写成员本人的邮箱，创建成功后系统将自动向该邮箱发送登录信息，成员将通过该信息登录扣子。每位成员的邮箱必须唯一，不可重复。
   * 团队版子账号不支持绑定手机号，也不支持修改密码、手机号或邮箱。
   * 密码默认为自动生成的随机密码，你也可以根据页面提示，为员工设置密码。
4. 成功添加成员后，此成员将收到一封通知邮件，可使用邮件中的登录名和密码登录扣子。
   具体登录方式可参考[注册登录](/coze_sign_up)。

@tab 分享邀请链接
分享二维码或邀请链接，成员扫码或打开链接后可申请加入企业。该方式创建成员时，成员可自行设置账号密码。

1. **超级管理员**登录[团队管理后台](https://admin.coze.cn/)。
2. 在**企业成员管理 > 成员列表**页面中，单击**邀请 > 添加成员**。
3. 选择**分享链接邀请加入**。
4. 保存二维码，或复制分享链接，通过其他通讯工具将其发送给成员。
   * 超管可重置链接，重置后，之前生成的分享链接将全部失效。
   * 链接和二维码默认有效期 7 天，也可以按需延长，失效后超管需要再次获取链接和二维码。
5. 成员扫码或打开链接，在信息收集页面填写自己的登录名、密码和昵称，并单击**确认加入**。
6. 管理员登录[团队管理后台](https://admin.coze.cn/)，打开**企业成员管理 >  邀请管理**页面，通过申请。
   默认情况下，通过分享链接加入团队时，需要团队管理员审核。管理员也可以在**邀请成员**页面关闭此设置，无需审批即可加入。
7. 审批通过后，此成员可使用自行设置的登录名和密码登录扣子团队版。
   具体登录方式可参考[注册登录](/coze_sign_up)。
::::

### 步骤二：通知登录信息 {#dc4e2ce5}

企业超级管理员创建成员后，需将成员登录信息提供给对应的成员，成员将通过该信息登录扣子编程。支持以下两种方式：

* 如果你在创建成员时，勾选了短信或邮件通知方式，系统自动通过短信或邮件方式发送成员登录信息给用户。
* 将你已复制的成员登录信息，发送给用户。

成员信息示例如下：

:::tip 说明
登录链接有效期为 30 天。
:::

```Plain Text
登录地址：https://****3D2382847030528
企业别名：测试**
用户名：test**
密码：Go**
```

1. 企业超级管理员或管理员登录[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)。

   ::::tabs

## 常见问题 {#6ea14d2b}

### 加入企业后，如何登录扣子？ {#d85f594f}

企业员工登录扣子，可参考[企业/团队员工登录](/guides/sign_up#69e772ec)。

### 如何查看企业别名？ {#fd1975c4}

针对企业版，你可以在[火山引擎扣子控制台](https://console.volcengine.com/coze-pro/overview)**成员管理**页面的**扣子登录信息**区域，查看自己所在企业的别名。团队版无企业别名。

![Image=627x159](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3e587896dd5144f1a687d0244ec7c498~tplv-goo7wpa0wc-topic.webp)

### 如何获取用户名称？ {#12feca48}

你可以在**账号设置**页面，查看自己的用户信息，包括扣子用户名、用户昵称等。

![Image=397x272](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ab35c166ed02429fa337a6bbb10540be~tplv-goo7wpa0wc-topic.webp)

### 如何修改成员名称？ {#e4e32b73}

* **企业版**：创建成员后，无法修改其**企业（火山）成员名**，该名称是成员登录扣子编程时必须使用的账号。
* **团队版**：团队版成员没有**企业（火山）成员名**，其扣子成员名也不支持修改。

### 如何设置禁止员工加入外部企业或空间 {#562dcd5e}

企业超级管理员或管理员可以设置禁止企业员工加入第三方工作空间和企业，有助于防止敏感信息通过第三方平台外泄，保障组织信息资产的可控性与合规性。默认允许企业成员加入第三方工作空间和企业。

1. 企业超级管理员或管理员登录[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)。
2. 在左下角单击个人头像，选择**企业账号**> **企业管理**。
   ![Image=287x229](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1f731b8e76e54a83a64f5dec38b10c38~tplv-goo7wpa0wc-topic.webp)
3. 在扣子编程的**企业成员管理>成员权限**页签下，开启**禁止企业员工加入第三方工作空间和企业**右侧的开关。默认允许企业员工加入第三方工作空间和企业。
   ![Image=532x100](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/acccd365236748b3bf9218851ecdcbd3~tplv-goo7wpa0wc-topic.webp)
   * 如果页面提示有成员已加入第三方工作空间或企业，若需要他们退出第三方工作空间或企业，你需手动联系相关用户退出，扣子编程不会自动将其移出第三方工作空间或企业。
   * 如果企业中没有已加入第三方工作空间或企业的成员，则不会提示。

## 后续操作 {#8cc31d34}


* **将成员加入组织（可选）**：成员加入企业时，会同时加入默认组织。团队尊享版和企业旗舰版支持创建多个组织，对工作空间和企业员工分组管理，创建组织并添加成员的方式可参考[创建组织](/guides/manage_organization)、[添加组织成员](/guides/add_organization_member)。
* **将成员加入工作空间（可选）**：工作空间所有者和管理员需要邀请组织成员加入工作空间，以便其在工作空间中进行项目创建和协作，具体请参考[邀请用户加入空间](/guides/invite)。
