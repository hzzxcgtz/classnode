企业是扣子编程中的虚拟架构，享有多人协作等高级权益。扣子编程面向中小型团队和大型企业推出团队版、企业版套餐。购买套餐后，应尽快创建企业并添加员工，实现企业成员协同开发中大型 AI 应用。

:::tip 说明
* 一个主账号仅能创建一个企业，且**创建后无法删除**。
* 企业版需由套餐购买者手动创建企业。
* 购买团队版后，系统会自动创建企业及配置默认的企业名称和头像，你可以按需修改。如果创建失败，套餐购买者可以参考本文手动创建。
:::

## 前提条件 {#fa0fea78}

已购买团队版套餐或企业版套餐。更多信息，请参考[团队版](/coze_pro/team_plan)、[企业版](/coze_pro/enterprise_plan)。

## 操作步骤 {#29a2c22e}

以下步骤适用于企业版创建企业，或团队版自动创建企业失败后的手动创建场景。

1. 套餐购买者登录[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)，系统将提示你创建企业。
2. 输入**企业名称**，设置**企业图标**，单击**创建企业**。
   企业创建成功后，系统将自动跳转至扣子编程的**组织管理**页面。在此页面，您可以创建企业的工作空间，具体请参见[创建并管理空间](/guides/manage_teams)。
