当企业版、团队版变更套餐或组织解散时，你可以删除非默认组织。默认组织不支持删除。

:::tip 说明
* **套餐限制**：团队尊享版、企业旗舰版
* **角色限制**：默认情况下，组织超级管理员、企业超级管理员可操作。
* **访问控制**：在团队版和企业版中，企业超级管理员可以通过**功能访问控制**，控制功能的可见范围。如果你未看到预期的功能，请联系企业超级管理员确认。更多信息，请参考[功能访问控制](/guides_team_config#hnd1HfjfQ)。
* **删除的影响**：组织删除后，该组织下所有资源都将被删除，已发布的智能体、应用等都将无法继续使用，且不可恢复，请谨慎操作。如果需要备份组织中的工作流，你可以导出工作流，具体请参见[导出与导入工作流](/guides/use_workflow#05adc46d)。
:::

## 前提条件： {#dd3547ae}

* 已删除组织内的所有工作空间。
* 已删除 OAuth 应用、服务身份及凭证、个人访问令牌。

## 操作步骤： {#15d10286}


1. 在[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)左下角单击个人头像，选择企业账号，然后单击对应组织的**设置**图标。
   ![Image=305x240](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ef39c42de42a410e8abdd70c983aca1c~tplv-goo7wpa0wc-topic.webp)
2. 在**企业组织管理**页面，在顶部选择**组织设置**页签，单击**删除组织**。如果组织中有未清理的资源，按页面提示清理后再删除。
