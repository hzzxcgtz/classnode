## 升级企业版、团队版之后，为什么仍然是个人版权益？ {#a42c0bc9}

升级企业版或团队版之后，在你的个人账号基础上会增加一个企业账号，你必须创建企业、并切换到企业中才能享受企业版或团队版的高级权益。你在个人账号下只能享受个人版的权益。

![Image=496x233](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/dc6bcdcdc81644068c501691e47190f8~tplv-goo7wpa0wc-topic.webp)

切换到企业账号的操作如下：

在扣子编程左下角单击个人头像，单击企业名称，选择对应的组织。

![Image=249x199](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7a40a9c28dfd41a5b026fe5c8fc69e00~tplv-goo7wpa0wc-topic.webp)

## 升级企业版之后，为什么子用户仍然是免费版？ {#fecc33c8}

**子用户必须加入企业之后，才能享受企业版的高级权益**。将子用户添加到企业中的操作步骤如下：

1. 企业超级管理员或管理员在扣子编程左下角单击个人头像，选择企业账号 > **企业管理**。
   ![Image=238x190](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a3ec0e88febc4c60ba234e60f6fd3668~tplv-goo7wpa0wc-topic.webp)
2. 在顶部选择**成员管理**页签。在成员列表页面，单击**+成员**。
3. 选中已创建的子用户，设置其身份，然后单击**确认**。
   ![Image=600x397](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fa86f86b8315444a89f6b8304f916f18~tplv-goo7wpa0wc-topic.webp)   


## 可以邀请外部用户加入企业吗？ {#1e3530f3}

扣子编程支持邀请外部用户（访客）加入企业。扣子编程默认禁止访客加入企业，超级管理员或管理员可以设置允许访客加入企业，非企业内部成员的外部用户即可加入企业。

![Image=500x284](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/27770e3bf2b7439599d0a514600aabeb~tplv-goo7wpa0wc-topic.webp)

## 是否支持跨企业迁移资源？ {#f48742b7}

暂不支持。目前扣子编程暂不支持将智能体、工作流等资源从一个企业的空间迁移到另一个企业中。

## 企业成员与工作空间成员有什么关系？ {#797bff17}

企业成员与工作空间成员属于不同的角色体系。

* 企业成员：企业包含超级管理员、管理员、员工和访客四种角色，员工和访客统称为成员。成员被添加到企业后，可以和超级管理员共享企业中的高级权益与海量资源。所有企业成员均可独立登录扣子编程。
* 工作空间成员：工作空间包含空间所有者、空间管理员和空间成员三种角色。成为企业成员后，才能被邀请加入该企业下的工作空间，成为工作空间成员。工作空间成员的权限通常由该工作空间的所有者或管理员设置，这些权限仅限于工作空间内的操作。

企业超级管理员和管理员具备工作空间的管理权限。如何成为企业成员，请参考[企业版成员](/guides/create_member#22807250)；如何成为工作空间成员，请参考[邀请用户加入空间](/guides/invite)。

## 一个账号可以加入多个企业吗？ {#36110bd0}

一个账号可以同时加入多个企业，但角色有所不同。作为员工，一个账号只能属于一个企业；而作为访客，则可以加入多个企业。

## 访客具备哪些权限，与员工有什么差异？ {#bbbcb709}

访客的操作权限请参见[成员与权限](/guides/team_and_enterprise_overview#3669986e)，访客和员工在权限上存在以下主要差异：

* **管理权限**：访客不能作为企业的管理员，也不能作为空间管理员，仅能作为普通空间成员参与协作。
* **资源操作权限**：访客可以在企业的工作空间内创建、使用资源（音色除外），并可发布和删除自己创建的资源，包括智能体、应用、工作流、插件等。
* **API 权限**：访客不支持创建个人访问令牌、 OAuth 访问令牌、也不支持通过企业 API 页面调用扣子编程 OpenAPI。

## 访客在企业内的费用由谁承担？ {#a50acecc}

访客加入企业后，在企业工作空间内产生的费用由企业承担，并占用企业席位。但需要注意的是，访客访问扣子商店和模板所消耗的费用将从访客个人的积分中扣除。

## 为什么我没有看到某个功能、资源？ {#hhJJAEjN8}

在团队版和企业版中，企业超级管理员可以通过**功能访问控制**和**空间资源访问控制**，控制成员可见的功能入口和工作空间资源范围。

如果你看不到某个功能，可能是你所在的角色、组织、成员账号或空间被设置了访问限制。如需使用该功能，请联系企业超级管理员确认。更多信息，请参考[功能访问控制](/guides_team_config#hnd1HfjfQ)。

如果你可以进入**项目管理**、**资源库**或**任务中心**，但看不到某些工作空间资源，可能是该空间配置了**空间资源访问控制**，限制了不同角色成员的资源可见范围。该配置仅影响资源可见范围，不会删除已有数据。更多信息，请参考[空间资源访问控制](/guides_team_config#hCId5unoV)。
