## 扣子助手 {#UVq4IVyDnc}

建议优先通过扣子助手获取帮助。扣子助手是扣子团队提供的产品知识问答智能体，旨在于帮助扣子用户解决使用扣子过程中的咨询问题，尝试分析报错信息，协助处理异常场景。

* **网页端、桌面端**：
   你可以在[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)或[扣子](https://www.coze.cn/?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)页面左下角单击**你的头像** > **帮助与反馈** > **帮助中心**，随时唤起扣子助手。
   和扣子助手对话，发送你的具体问题，扣子助手会尽力帮你解决。

## 扣子在线客服（个人尊享版） {#online-service}

**个人尊享版**用户可以通过在线客服获取实时的人工支持。扣子在线客服工作时间为工作日 10:00 -12:00，13:00-19:00。

* **网页端、桌面端**：在[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)或[扣子](https://www.coze.cn/?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)页面左下角单击**你的头像** > **帮助与反馈** > **帮助中心**，在帮助中心面板底部单击**在线客服**。进入在线客服后，在输入框中描述你遇到的问题，客服会根据你的问题提供对应帮助。

## 火山技术支持（企业版） {#rC0v0Kl0Fz}

企业版（标准版、旗舰版）付费套餐，由火山引擎提供售后服务。你可以通过[火山售后在线咨询](https://console.volcengine.com/coze-pro/overview?entry=ConsoleSideBarAftermarket&openVcopilot=%7B%22query%22:%22%22,%22displayMode%22:%22fullscreen%22%7D&vcopilotExtraInfo=%7B%22accountPlanName%22:%22%E4%BC%81%E4%B8%9A%E7%89%88%22%7D)提交工单，获取人工客服支持。提交工单之前，建议整理并收集报错场景、错误码等信息，以便工程师尽快定位你的问题。

:::tip 说明
* 并非所有异常场景均可获取 Logid、错误码以供排查，你也可以提供异常场景的具体描述及截图，并提交反馈。
* 为企业标准版提供工作日 10:00～19:00 的人工客服支持，为企业旗舰版提供 7✖️24 小时的全天候人工客服支持。具体服务范围，请参考[客户服务](/guides/edition#75617e0a)。
:::
