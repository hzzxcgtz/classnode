在企业中，空间所有者和管理员可以邀请其他扣子用户加入工作空间。

## 功能简介 {#2630c5b2}

在企业中，空间所有者和管理员可以邀请企业成员（子用户）和外部用户（访客）加入工作空间。用户加入工作空间前，需先将其添加至对应企业和组织，具体操作请参见[创建成员](/guides/create_member)、[添加组织成员](/guides/add_organization_member)。

:::tip 说明
* **套餐限制**：团队高阶版、团队旗舰版、团队尊享版、企业标准版、企业旗舰版
* **角色限制**：空间所有者和管理员。
* **访客限制**：访客加入空间后，只能作为空间成员，不能作为空间管理员和空间所有者。
* **空间成员数量限制**：团队高阶版、团队旗舰版、企业标准版空间最多 100  人，团队尊享版、企业旗舰版空间人数无限制。
* **访问控制**：在团队版和企业版中，企业超级管理员可以通过**功能访问控制**，控制功能的可见范围。如果你未看到预期的功能，请联系企业超级管理员确认。更多信息，请参考[功能访问控制](/guides_team_config#hnd1HfjfQ)。
:::

## 设置允许外部用户加入空间 {#837db85d}

在工作空间中，如果需要邀请外部用户加入空间，应由**空间所有者**或**管理员**关闭**禁止外部用户加入当前空间**。

1. 登录[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)。
2. 在左下角单击个人头像，选择企业账号，然后单击对应组织的**设置**图标。
   ![Image=316x248](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/959e39622d9b4a34895f5c49e1215c65~tplv-goo7wpa0wc-topic.webp)
3. 在**组织管理**页面的顶部选择**空间管理**，然后单击目标工作空间对应的**设置**。
   ![Image=386x197](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5f86215a64a043d58c92b8d8b9d4bcbc~tplv-goo7wpa0wc-topic.webp)
4. 在顶部选择**空间设置**页签，关闭**禁止外部用户加入当前空间**。
   ![Image=600x306](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d79e03d505504d2380a019d5913f5ce5~tplv-goo7wpa0wc-topic.webp)   


## 通过链接邀请用户 {#d2c46604}

**空间所有者**和**空间管理员**可以开启空间的邀请链接，其他扣子用户访问邀请链接来加入空间。此方式适用于不了解用户昵称或用户名、用户数量较多的情况，例如培训授课时邀请学员加入空间。

:::tip 说明
* 空间邀请链接的有效期为 7 天，超期后需要重新复制链接。空间所有者或管理员也可以手动关闭分享链接，关闭后其他用户将无法通过链接加入空间。重新开启邀请链接后，之前的访问链接会失效。
* 空间的邀请链接是完全公开的，所有用户均可以通过邀请链接加入空间。为保障信息安全和数据安全，需要注意邀请链接的传播范围，或者在**成员与设置** > **空间设置**页面开启**禁止外部用户加入当前空间**。
:::

1. 登录[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)。
2. 在左下角单击个人头像，选择企业账号，然后单击对应组织的**设置**图标。
   ![Image=304x239](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9191553ef8c443acae6ed31cc67b5c0f~tplv-goo7wpa0wc-topic.webp)
3. 在**组织管理**页面的顶部选择**空间管理**，然后单击目标工作空间对应的**设置**。
   ![Image=386x197](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5f86215a64a043d58c92b8d8b9d4bcbc~tplv-goo7wpa0wc-topic.webp)
4. 在顶部单击**成员管理**页签，在右上角单击**邀请链接**图标。
5. 开启邀请链接。单击**复制链接**。
   ![Image=583x219](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d57e4884f8a3470e80c46a0bedb6f300~tplv-goo7wpa0wc-topic.webp)
6. 将链接转发给其他扣子用户，用户访问链接时可以选择是否加入空间。
   ![Image=257x337](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fe99d1f59f2f405bb6467a6423712149~tplv-goo7wpa0wc-topic.webp)   


## 直接添加用户 {#9f41ac7f}

如果你已获取扣子用户的昵称或用户名，可直接将其加入工作空间。企业版还支持通过火山成员名加入。

1. 登录[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)。
2. 在左下角单击个人头像，选择企业账号，然后单击对应组织的**设置**图标。
   ![Image=329x258](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7ef8e091c1f04f4d9e23ee3ea6a90c75~tplv-goo7wpa0wc-topic.webp)
3. 在**组织管理**页面的顶部选择**空间管理**，然后单击目标工作空间对应的**设置**。
   ![Image=386x197](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5f86215a64a043d58c92b8d8b9d4bcbc~tplv-goo7wpa0wc-topic.webp)
4. 在顶部单击**成员管理**页签，在右上角单击 **+ 添加成员**。
5. 输入扣子用户的用户名、用户昵称或火山成员名（企业版）搜索用户，并设置用户角色。
   用户角色的差异可参考[设置空间成员角色](/guides/set_role)。
   ![Image=510x281](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/bc832b02359146d8a2635c365f6cb95e~tplv-goo7wpa0wc-topic.webp)
   :::tip 说明
   用户可以在扣子编程的**个人信息**页面查看自己的用户名等信息。具体操作，请参考[如何获取用户名称？](/guides_create_member#12feca48)。
   :::
