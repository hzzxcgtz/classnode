组织是企业下的虚拟分组，在大中型企业中，可根据部门或项目维度将工作空间划分到不同组织，实现多业务部门的独立运作与统一管理。本文介绍如何创建组织以及对组织进行查询和修改等操作。

:::tip 说明
* **套餐限制**：团队尊享版、企业旗舰版。
* **数量限制**：最多可添加 50 个组织。
* **角色限制**：默认情况下，企业超级管理员或管理员可操作。
* **访问控制**：在团队版和企业版中，企业超级管理员可以通过**功能访问控制**，控制功能的可见范围。如果你未看到预期的功能，请联系企业超级管理员确认。更多信息，请参考[功能访问控制](/guides_team_config#hnd1HfjfQ)。
:::

## 功能简介 {#29abe1fc}

每个企业包含一个默认组织，用户加入企业时将自动加入该默认组织。企业旗舰版++和++团队尊享版支持创建多个组织，其企业超级管理员和管理员可以按部门或项目创建组织，通过组织这一维度，企业可精细化管理成员与权限、实现资源的规范化配置，提高企业内部的协作效率。

## 操作步骤 {#27857f3e}

1. 企业超级管理员或管理员登录[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)。
2. 在左下角单击个人头像，选择**企业账号**> **企业管理**。
   ![Image=263x210](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/72c146b1edd64d84adb85a1a5088831e~tplv-goo7wpa0wc-topic.webp)
3. 在左侧导航栏选择**企业组织管理**，单击右上角的**创建组织**。输入组织名称和描述，单击**确认**。
   ![Image=644x227](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c54c9e6983c748b681b99c40a38647de~tplv-goo7wpa0wc-topic.webp)

### 修改组织名称 {#254c495b}

:::tip 说明
**角色限制**：组织超级管理员。
:::

1. 在[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)左下角单击个人头像，选择企业账号，然后单击对应组织的**设置**图标。
   ![Image=254x200](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c6885c00f66b4a7f9573d49990d38155~tplv-goo7wpa0wc-topic.webp)
2. 在**组织设置**页面，单击组织名称后面的**修改**图标，修改组织名称。
   ![Image=496x337](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/127e668a29fe46a59f101428da570183~tplv-goo7wpa0wc-topic.webp)
