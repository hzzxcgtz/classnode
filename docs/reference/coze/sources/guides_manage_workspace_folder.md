你可以通过文件夹对项目开发页面中的应用和智能体进行归类，提升查找效率。例如教师可以为每个课时创建文件夹，以便管理不同课时的教学内容。

## 使用限制 {#95a9a55c}

:::tip 说明
* **角色限制**：默认仅**空间所有者**和**管理员**可以创建、编辑和删除文件夹。如需允许空间成员创建和编辑文件夹，请在**空间设置**页面开启相关权限，具体步骤参见[新建、编辑文件夹权限](/guides/publish_permission#d2dce2eb)。
* **数量限制**：单个工作空间最多创建 **1000** 个文件夹。
* **文件夹层级**：最多 **10** 层。
* **访问控制**：在团队版和企业版中，企业超级管理员可以通过**功能访问控制​**和**空间资源可见性**，控制成员可见的功能入口和空间资源范围。如果你未看到预期的功能和资源，请联系企业超级管理员确认。更多信息，请参考[功能访问控制](/guides_team_config#hnd1HfjfQ)和[空间资源访问控制](/guides_team_config#hCId5unoV)。
:::

## 操作步骤 {#3ab6a73d}

1. 创建文件夹。
   在扣子编程顶部选择对应工作空间，在左侧导航栏选择**项目管理**，单击右上角的**新增文件夹**，输入文件夹名称并确认创建。
   ![Image=500x111](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e2956ba9966545ce996334a3a521e2be~tplv-goo7wpa0wc-topic.webp)
2. 将资源移入文件夹。
   **空间所有者**、**管理员**和**资源所有者**可以将资源移入对应文件夹。
   选择目标资源，单击**移动**，选择目标文件夹，单击**确定**。

## 相关操作 {#f1eb12a0}

### 删除文件夹 {#252262ac}

删除文件夹前，你需要先将文件夹内的子文件夹和资源清空。

选择目标文件夹，单击更多选项，选择**删除**。
