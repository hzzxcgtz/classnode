感谢您一直以来对扣子编程 OpenClaw 的体验与支持。由于 OpenClaw 项目的部署与运维成本较高，扣子（coze.cn）也提供了更轻量、交互更友好的 OpenClaw Agent，因此我们将对扣子编程中的 OpenClaw 项目服务进行调整，具体如下：

## **调整时间及内容** {#19e18ee5}

自 **2026 年 6 月 30 日起**，扣子编程将不再支持创建新的 OpenClaw 项目。

已创建和已部署的 OpenClaw 项目不受影响，您仍可继续正常使用。

## 替代方案 {#0be130a0}

后续如需创建和部署 OpenClaw 项目，您可以前往 [扣子 3.0 首页](coze.cn) **新建云端 Agent**，使用新版 OpenClaw 创建方式。

在与[扣子](https://www.coze.cn/?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)的对话列表中，单击「新建 Agent」并选择「新建云端 Agent」，选择 「OpenClaw」框架并部署，就能拥有新的 OpenClaw Agent。

通过扣子 3.0 创建的 OpenClaw 项目，优势如下：

* **开箱即用**：云端 Agent 运行在扣子提供的**云端服务器**中，与您的本地设备完全隔离，无需安装任何软件、配置环境或处理网络配置问题，创建即用，**秒级启动**。
* **稳定在线**：云端 Agent 不依赖本地电脑在线，7×24 运转，适合**长任务、自动化和值守**等场景。
* **项目协作**：在项目中，你可以邀请人类成员和多个 Agent 加入，实现多人多agent共同协作。
* **更多框架支持**：除 OpenClaw 外，云端 Agent 还支持 **Claude Code、Codex CLI** 等 Agent 框架，多个 Agent 可部署在同一台云电脑上，保持长期稳定在线。
