你可以灵活配置工作空间成员的资源创建与发布权限，满足多样化协作需求。

:::tip 说明
* **套餐限制**：团队版、企业版。
* **角色限制**：空间所有者和空间管理员。
* **功能和资源访问控制**：在团队版和企业版中，企业超级管理员可以通过**功能访问控制​**和**空间资源可见性**，控制成员可见的功能入口和空间资源范围。如果你未看到预期的功能和资源，请联系企业超级管理员确认。更多信息，请参考[功能访问控制](/guides_team_config#hnd1HfjfQ)和[空间资源访问控制](/guides_team_config#hCId5unoV)。
:::

## 功能简介 {#c6fd405d}

空间所有者和空间管理员可通过成员权限管控，对工作空间成员的资源创建权限与发布权限进行精细化管理，减少非必要成员操作导致的资源混乱或风险，从而提升资源管理的规范性与安全性。具体包括：

* 资源创建权限：默认允许工作空间内的所有成员创建智能体、应用、知识库、数据库、插件。也可以设置仅允许空间所有者和管理员创建对应的资源。工作流、音色和卡片不受此限制。
* 资源发布权限：默认允许工作空间内的所有成员发布智能体和应用，也可以配置仅限白名单成员发布。

## 资源发布权限 {#092c12d5}

默认允许工作空间内的所有成员发布智能体和应用，适用于组织成员高度信任且协作紧密的场景，可快速推动项目进展。若需限制发布权限以保障项目质量和安全性，可添加允许发布的成员名单，实现更精细的权限管理。

3. 在**组织管理**页面的顶部选择**空间管理**，然后单击目标工作空间对应的**设置**。
   ![Image=386x197](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5f86215a64a043d58c92b8d8b9d4bcbc~tplv-goo7wpa0wc-topic.webp)
4. 在顶部选择**权限管理**页签，单击**资源发布**页签，开启**允许全部成员发布**的开关。
   ![Image=567x143](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f9da09d4a693445097912e7bacbaf643~tplv-goo7wpa0wc-topic.webp)

3. 在**组织管理**页面的顶部选择**空间管理**，然后单击目标工作空间对应的**设置**。
   ![Image=386x197](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5f86215a64a043d58c92b8d8b9d4bcbc~tplv-goo7wpa0wc-topic.webp)

## 资源创建权限 {#f8cf0037}

默认允许工作空间内的所有成员创建智能体、应用、知识库、数据库、插件。若需限制仅允许空间所有者和管理员创建对应类型的资源，你可以关闭对应资源类型的创建权限。

1. 登录[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)。
2. 在左下角单击个人头像，选择企业账号，然后单击对应组织的**设置**图标。
   ![Image=303x238](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/109bb065897b402c86c2d7f7d9b153a4~tplv-goo7wpa0wc-topic.webp)
3. 在**组织管理**页面的顶部选择**空间管理**，然后单击目标工作空间对应的**设置**。
   ![Image=386x197](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5f86215a64a043d58c92b8d8b9d4bcbc~tplv-goo7wpa0wc-topic.webp)
4. 在顶部选择**权限管理**页签，单击**资源创建**页签，设置资源创建权限：
   * **允许空间成员创建资源**：开启对应资源类型右侧的开关。
   * **仅允许空间所有者和管理员创建资源**：关闭对应资源类型右侧的开关，在确认对话框中单击**关闭**。
      ![Image=512x203](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/22829264203f42afa9cf4bd5510c1b2e~tplv-goo7wpa0wc-topic.webp)      


## 新建、编辑文件夹权限 {#d2dce2eb}

默认情况下，仅工作空间所有者和管理员可新建、编辑文件夹。如果需要调整文件夹的新建、编辑权限，可以在空间设置中修改「新建、编辑文件夹权限」开关。

1. 登录[企业管理](https://admin.coze.cn/)（admin.coze.cn）页面。
2. 在**组织管理** > **空间管理**页面，找到指定的工作空间，并单击**设置**。
   ![Image=386x197](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5f86215a64a043d58c92b8d8b9d4bcbc~tplv-goo7wpa0wc-topic.webp)
4. 在顶部选择**空间设置**页签，设置文件夹权限：
   * 开启「新建、编辑文件夹权限」开关后，仅工作空间所有者和管理员可新建、编辑文件夹。
   * 关闭「新建、编辑文件夹权限」开关后，空间内所有成员均可新建、编辑文件夹。
      ![Image=565x225](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/83fa9b870b1941e985295c1061f58f9e~tplv-goo7wpa0wc-topic.webp)      


## 常见问题 {#66734f23}

### 访客能创建文件夹吗？ {#93414eb5}

如果空间所有者设置了**允许空间成员新建、编辑文件夹**，访客加入工作空间后，可以新建文件夹。
