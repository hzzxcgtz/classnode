在人员离职等场景下，企业可彻底移除该成员，从而有效保护企业数据安全。移除后，该成员将无法通过成员账号访问扣子，且不再占用企业内的成员数量。

## 操作流程 {#b7f9faf7}

移除企业成员的操作流程如下图所示。

![Image=612x112](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8c237819defa46dc823859b819c9f243~tplv-goo7wpa0wc-topic.webp)

> 团队版暂不支持删除成员账号。

## 步骤一：从空间移除成员（可选） {#94811afc}

:::tip 说明
* **角色权限**：默认情况下，工作空间所有者或管理员可操作。
* **访问控制**：在团队版和企业版中，企业超级管理员可以通过**功能访问控制**，控制功能的可见范围。如果你未看到预期的功能，请联系企业超级管理员确认。更多信息，请参考[功能访问控制](/guides_team_config#hnd1HfjfQ)。
:::

**建议执行本步骤。** 跳过本步骤时，系统会在移出组织时自动将成员移出工作空间，但其名下资源将统一转交给组织超级管理员或管理员，可能导致资源过度集中。

执行本步骤，可将资源转移给原项目团队成员，减少后续交接成本。

1. 在[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)左下角单击个人头像，选择企业，然后单击对应组织的**设置**图标。
   ![Image=302x237](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7b43ee63b56d4e3eb644c330db30f75c~tplv-goo7wpa0wc-topic.webp)
2. 在**组织管理**页面的顶部选择**空间管理**，然后单击目标工作空间对应的**设置**。
   ![Image=487x250](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9b651a301e0f4c14a1fb9806266a5aa1~tplv-goo7wpa0wc-topic.webp)
3. 在**空间管理**页面的顶部，单击**成员管理**页签。
4. 单击目标成员右侧的**移除**图标，在弹出的对话框中，选择将该成员拥有的智能体、工作流等资源转移给空间的所有者或其他成员。
   ![Image=500x222](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/61bede88af5b4918b66f750e96f14fdb~tplv-goo7wpa0wc-topic.webp)
5. 单击**移除成员**。

## 步骤二：从组织移除成员 {#9729d147}

如果成员因离职等场景需要删除该成员，可以由组织超级管理员或管理员将其移出组织（包括默认组织），或让成员主动离开组织。移出组织后，该成员拥有的工作空间、智能体、工作流等资源转移给组织的超级管理员或管理员。

4. 单击目标成员右侧的**移除**图标，在弹出的对话框中，选择将该成员拥有的工作空间、智能体、工作流等资源转移给组织的超级管理员或管理员。
   ![Image=552x167](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/66755f13b35e4559aafaf3282ebceb34~tplv-goo7wpa0wc-topic.webp)

## 步骤三：从企业移除成员 {#52098e26}

移除组织成员后，你还需要将其从企业中移除，移除企业成员仅表示其在当前企业中的扣子权限被撤销，不会删除该账号。如后续需要重新启用，管理员可再次将其加入企业。

:::tip 说明
* **角色权限**：默认情况下，企业超级管理员或管理员可操作。
* **访问控制**：在团队版和企业版中，企业超级管理员可以通过**功能访问控制**，控制功能的可见范围。如果你未看到预期的功能，请联系企业超级管理员确认。更多信息，请参考[功能访问控制](/guides_team_config#hnd1HfjfQ)。
* **团队版**：从企业移除后，成员账号将无法登录扣子。
* **企业版**：从企业移除后，成员账号仍可以登录扣子，可使用个人免费版资源，但无法访问企业资源。
   确定不再使用该成员时，建议在火山引擎扣子控制台成员管理页面将其彻底删除，以确保账号安全和资源合理管理。
:::

1. 企业超级管理员或管理员登录[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)。
2. 在左下角单击个人头像，选择**企业账号**> **企业管理**。
   ![Image=289x227](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0a40c6b7092d4646aef7bf7854287df5~tplv-goo7wpa0wc-topic.webp)
3. 在左侧导航栏选择**企业成员管理**，然后在**成员管理**页面，单击目标成员对应的移除图标，将成员从当前企业中移除。
   ![Image=402x193](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/20cddf600e654b8aa6ef948f96c20e5e~tplv-goo7wpa0wc-topic.webp)
4. 选择将成员的所有资源转移给企业的超级管理员或管理员。
5. 单击**移除成员**。

## 步骤四：删除成员（企业版） {#aa3e2e26}

**企业版套餐**可以在火山引擎控制台将成员绑定的子用户删除，彻底回收账号权限。团队版暂不支持删除成员账号。

:::tip 说明
* **角色权限**：企业超级管理员，或拥有 **CozeFullAccess** 权限的 IAM 子用户。
* **前置要求**：执行本步骤前，请确认以下事项已完成：
   * 该成员在扣子企业内的**所有资源已成功转移**给其他成员。
   * 该成员已从企业中移除。
      **如果成员未从企业中移除，直接在火山引擎扣子控制台删除成员，该成员在扣子编程内会变为失效状态，但仍占有已购买的成员席位数。**
:::

在[火山引擎扣子控制台](https://console.volcengine.com/coze-pro/user/list)的**成员管理**页面，找到目标成员，单击**删除**。

企业超级管理员也可以通过扣子编程**创建内部成员账号时**，直接跳转到火山引擎扣子控制台，该方式无需通过火山引擎账号进行登录。
