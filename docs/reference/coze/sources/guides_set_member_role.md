1. 企业超级管理员或管理员登录[扣子编程](https://code.coze.cn/home?surl_token=FJvCs&zlink_code=FFKdE&utm_medium=docs&utm_source=docs&utm_content=landingpage&utm_id=&utm_campaign=&utm_term=docs&utm_source_platform=)。
2. 在左下角单击个人头像，选择**企业账号**> **企业管理**。

3. 在左侧导航栏选择**企业成员管理**，在**成员列表**页面，修改成员的身份为企业管理员或企业员工。

## 设置成员在组织中的角色 {#f8388581}

组织创建者默认为组织的超级管理员，企业超级管理员申请加入组织后，直接加入成功且为组织的超级管理员。

**组织的超级管理员和管理员**可以修改内部成员的角色为组织的超级管理员、管理员或员工。组织角色的权限说明请参见[成员与权限](/guides/team_and_enterprise_overview#3669986e)。

:::tip 说明
* 仅组织超级管理员能将员工设置为组织的超级管理员，组织管理员仅支持将员工设置为组织的管理员或员工。
* 外部成员的角色只能是访客。
* 组织超级管理员和管理员的数量暂时无限制。
:::

## 常见问题 {#93873b87}

### 组织管理员是企业管理员吗？ {#8541229d}

不是。组织管理员和企业管理员是两个不同维度的角色，可能由同一人担任，也可能由不同人担任，具体取决于对应的超级管理员的授权。具体区别如下：

* **组织管理员**：由组织超级管理员授权设置，其角色归属 “组织” 维度。组织内的员工、企业管理员都可以担任组织管理员，主要负责组织成员、工作空间的管理。
* **企业管理员**：由企业超级管理员授权设置，其角色归属 “企业” 维度。主要负责企业成员、企业组织的管理。
