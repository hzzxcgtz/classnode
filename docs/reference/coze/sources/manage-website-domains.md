一个网页应用可以同时拥有平台域名和自定义域名，也可以拥有多个可访问域名。本文介绍如何管理平台域名、设置主域名，以及调整域名的访问状态。

## 域名类型 {#hO4jyqNxQ}

### 平台域名和自定义域名 {#huiZr01WC}

扣子编程会为每个部署项目自动分配以 `.coze.site` 为后缀的初始**平台域名**。每个项目最多保留两个平台域名：一个系统初始平台域名和一个由用户新增的平台域名。系统初始平台域名不能删除。如果不希望它继续提供访问，可以将其停用。用户新增的平台域名可以修改前缀或删除。

你也可以将项目绑定至**自定义域名**，以便打造专属品牌访问地址，使网站地址更容易被用户记住，还能提升品牌知名度。

平台域名和自定义域名的主要区别如下：

<!-- @cols-width: 103,371,416 -->
| **功能**  | **平台域名**  | **自定义域名**  |
| --- | --- | --- |
| **备案**  | 扣子编程已统一备案，你无需单独备案。  | 需要在火山引擎备案域名。 | \
| | | | \
| | | 火山引擎域名或第三方域名均需要在火山引擎完成域名备案。  |
| **SSL 证书**  | 扣子编程已自动配置长期有效的 SSL 证书，无需手工配置。  | 需要手工配置证书。  |

### 主域名和可访问域名 {#hehk948Wr}

**主域名**是项目默认对外展示和推荐分享的访问入口。同一项目只能有一个主域名，但其他处于**可访问**状态的域名也可以直接访问同一网站。

## 管理网站域名 {#hSneSJeBB}

### 添加自定义域名 {#hA8Ak9Ywe}

在 AI 编程开发界面打开**部署**页面，选择**域名**页签，在自定义域名区域单击**添加域名**，根据页面提示即可添加自定义域名。详细步骤请参见《配置自定义域名》。

新添加的自定义域名会显示为**待配置**。完成备案、DNS 解析和 SSL 证书配置后，状态会变为**可访问**。

自定义域名不支持直接改名。如需更换域名，请添加新的自定义域名并重新完成配置。

![Image=519x278](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/60d8828ae70349daa9cef0e4d2e1f477~tplv-goo7wpa0wc-topic.webp)

### 添加和修改平台域名 {#hWLHECPuY}

除了系统默认分配的初始平台域名，你还可以自行添加一个新的平台域名。新增成功后，新的平台域名会展示在域名列表中，并自动被设置为**主域名**，初始平台域名仍然可访问。

::::details 添加平台域名的方式如下：
1. 在 AI 编程开发界面的**部署**页面，选择**域名**页签。
2. 找到平台默认域名，在右侧的折叠菜单中单击**新增平台域名**。
3. 为新域名设置一个自定义前缀，并单击**确认**。

![Image=450x240](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e3739ee545344ac3a44957b5d6a89f4f~tplv-goo7wpa0wc-topic.webp)
::::

用户新增的平台域名支持修改前缀。修改后，新域名会替换原用户平台域名，原域名将被释放。

:::tip 说明
修改域名前缀无需重新部署。修改后旧链接将失效，建议修改前后及时通知被分享过的用户。
:::

::::details 修改平台域名前缀的方式如下：
1. 在 AI 编程开发界面的**部署**页面，找到**部署域名**区域。
2. 单击编辑图标，输入新的域名前缀，并单击**确认修改**。

![Image=3222x1657](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/27612877505e4433a4f27cdd89f6638f~tplv-goo7wpa0wc-topic.webp)
::::

### 设置和更换主域名 {#hJVYP3bIb}

在域名列表中找到指定的域名，展开折叠菜单，选择**设为主域名**。设置成功后，该域名成为默认对外展示和推荐分享的入口，原主域名调整为可访问状态。

![Image=491x270](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1a17cf280ec949b3af63c07e0d3f7d97~tplv-goo7wpa0wc-topic.webp)

如果只想取消当前域名的主域名身份，选择**降级为可访问**，并从其他可访问域名中选择新的主域名。

![Image=495x229](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ce995f459fd346649edc4c86aefa397d~tplv-goo7wpa0wc-topic.webp)

### 设置或取消重定向 {#hITBBKdny}

在**可访问**域名右侧打开折叠菜单，选择**重定向到主域名**。设置后，用户访问该域名时会自动跳转到当前主域名。重定向只能指向主域名，不能指定其他目标地址。

![Image=476x288](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3ae6532a406d413c8885c03d504eec1a~tplv-goo7wpa0wc-topic.webp)

如需恢复该域名的直接访问能力，选择**取消重定向**。取消后，域名恢复为可访问状态。

![Image=479x291](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9a1239d3103f44628da681d91e5dfdc3~tplv-goo7wpa0wc-topic.webp)

### 停用或恢复访问 {#hVB6hKdtM}

在域名右侧打开更多菜单，选择**停用域名**。停用后，域名仍保留在列表中，但不可访问，也不会跳转。

停用主域名时，如果有其他可访问域名，需要先选择新的主域名；如果没有，仍可以停用，但项目将暂时没有公网访问入口。

如需重新启用域名，在停用域名右侧选择**恢复访问**，域名将恢复为可访问状态；也可以直接将停用域名设为主域名。

![Image=478x284](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b6e9f6832b61441483cdb7abd0034d19~tplv-goo7wpa0wc-topic.webp)

### 删除域名 {#hqRPPbga9}

在域名列表中找到自定义域名，在其右侧打开折叠菜单，选择**删除域名**。删除会解除域名与项目的绑定。

* 仅支持删除你添加的自定义域名，不可删除平台域名。若有需要，你可以停用平台域名。
* 删除主域名时，如果有其他可访问域名，需要先选择新的主域名。系统初始平台域名不能删除，只能停用。
* 删除自定义域名不会注销域名，也不会删除域名服务商或火山引擎侧的域名资产和证书。
