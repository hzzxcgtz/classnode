装进你的电脑

无需云服务器。无论你习惯用安装包还是手动源码部署，都可以在教师电脑上运行，学生用浏览器参与。

方式一：安装包 方式二：源码部署 启动后访问
推荐 · 零门槛

方式一安装包安装（推荐）

从项目 Release 页面 或 下载渠道 下载对应系统的安装包，双击即可完成安装。这是最简单、最推荐的方式。

💡 提示：统信 UOS 等 Linux 系统没有现成的安装包，请下载源码包，然后按下方「源码部署」步骤安装 Node.js 与 pnpm、构建并启动服务。

方式二本地源码部署

如果你有一定的技术基础，也可以下载源码通过命令行自行启动。Linux 平台建议使用此方式。Windows 和 macOS 用户建议直接使用安装包，体验最完整。

第一步：安装 Node.js

以统信 UOS 系统（ARM 架构）为例：

终端
# 1. 创建并进入软件目录
mkdir -p ~/software && cd ~/software

# 2. 下载（ARM 架构用 arm64，x86 架构用 x64）
wget https://mirrors.huaweicloud.com/nodejs/v24.16.0/node-v24.16.0-linux-arm64.tar.xz

# 3. 解压
tar -xvf node-v24.16.0-linux-arm64.tar.xz
mv node-v24.16.0-linux-arm64 nodejs24

# 4. 将 Node.js 加入环境变量
echo 'export PATH=$HOME/software/nodejs24/bin:$PATH' >> ~/.bashrc
source ~/.bashrc

第二步：更换 npm 源（国内用户推荐）

终端
npm config set registry https://registry.npmmirror.com

# 安装与项目一致的 pnpm 版本
npm install -g pnpm@11.3.0

# 检查是否切换成功
npm config get registry
# 预期输出: https://registry.npmmirror.com/

第三步：部署支点课堂

从 Release 页面 或 下载渠道 下载源码压缩包（如 classnode-2.1.4.tar.gz 或 classnode-2.1.4.zip），解压后进入目录。

在解压后的项目目录执行：

终端 · macOS / Linux
tar -xzf classnode-2.1.4.tar.gz
cd classnode-2.1.4

# 安装依赖、生成数据库客户端
pnpm install
pnpm db:generate

# 构建前后端，并组装静态页面
pnpm build:all

# 启动生产服务（保持终端打开）
pnpm start

要求 Node.js ≥ 24。Windows 源码部署可在解压后用 PowerShell 执行同样的 pnpm 命令；安装包用户无需安装这些开发工具。

首次部署：安装依赖需要联网。pnpm start 运行已构建的服务，不会自动构建项目；启动时自动同步数据库结构。退出终端会结束前台服务，需要长期运行时可另行配置系统服务或进程管理器。

源码升级：先在旧版本「数据管理」中下载备份；停止旧服务，部署新版本，再从页面上传并恢复备份。不要直接用新源码覆盖唯一的数据副本。

部署完成了？ 跳转到下方「启动后访问」，打开浏览器即可开始使用。
两种方式通用

通用启动后访问

无论选择安装包还是源码部署，启动完成后，在浏览器中访问以下地址即可使用：

  • 管理端：管理电脑 打开浏览器访问 http://localhost:3001/teacher/
  • 参与端：局域网内任意设备（平板、手机、其他电脑）访问 http://管理电脑IP:3001/classroom/
💡 提示：参与端通过局域网访问，只需将 localhost 替换为管理电脑的局域网 IP 地址即可（如 http://192.168.1.100:3001/classroom/）。
学生设备无需安装客户端或直接连接 AI 平台。教师电脑与学生设备须在可互通的局域网内；调用外部 AI 时，教师电脑仍须联网。
第一次开课：设置教师密码 → 建立班级与学生 → 制作学习单、上传探究网页或接入智能体 → 创建课堂并投屏发码。三件套任选其一即可开始；分组与高级模式需先建立小组。接入教程和提示词模板可在「AI 智能体」页打开。
💡 客户端连不上？Windows 系统默认的安全策略有时会误拦截网络。若客户端连接失败，请先确认教师端显示局域网访问已开放、设备处于同一网络，以及防火墙允许课堂服务。默认课堂端口为 3001；探究网页另用 3002。请在管理电脑上尝试：
方式一：打开「Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙」，勾选 支点课堂（ClassNode）（或 Node.js）的专用与公用网络（若无，点「允许其他应用」手动添加）。
方式二：进同页面的「高级设置 → 入站规则 → 新建规则」，按提示勾选：端口 → TCP → 输入 3001,3002 → 允许连接（请按学校网络管理要求设置）。
