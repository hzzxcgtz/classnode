# 学习单背景图制作规范

学习单背景用于营造轻松、亲切的学习氛围，不承担题目信息。题干、选项和输入控件始终应是页面主角。

## 横竖屏成套画布

- 每个主题建议同时制作横、竖两张同风格图片，而不是让一张图片兼顾所有比例。
- 横屏使用 3:2 画布，推荐 1536 × 1024 像素，最低不低于 1200 × 800 像素。
- 竖屏使用 3:4 画布，推荐 1200 × 1600 像素，最低不低于 900 × 1200 像素。
- 两张图应保持相同主题、配色和插画语言，但要重新排布装饰；不要把横图直接裁窄或拉伸。
- 中央约 70% 保持干净，只使用浅色底纹。
- 插画与装饰集中在画布四周 12%-15% 的范围内。
- 横图重点照顾左右边缘，竖图重点照顾上下边缘；重要装饰不要紧贴边缘。

## 色彩与内容

- 背景以浅色、低饱和、低对比为主，深色面积不超过画布的 10%。
- 不放可阅读文字、题号、二维码、校徽、水印和高频密集纹理。
- 不使用闪烁、强渐变、霓虹发光或容易被误认成按钮的形状。
- 适合使用云朵、植物、星球、海洋、文具等与学习和探索有关的边缘插画。

## 文件与性能

- 优先导出 WebP；需要透明区域时可用 PNG；照片类素材也可用 JPEG。
- 推荐单张不超过 300 KB，理想范围为 50-180 KB。
- 同一主题建议使用相同文件名，并为竖图添加 `-portrait` 后缀，例如 `forest-explorer.webp` 与 `forest-explorer-portrait.webp`。
- 系统允许上传的最大文件为 5 MB。上传前应先压缩。
- 使用 sRGB 色彩空间，避免在不同平板上出现明显偏色。

## 导出前检查

1. 在背景上叠一张白色或 96% 不透明度的题目卡片，确认深色正文清晰可读。
2. 分别在横屏和竖屏 iPad 预览对应图片，确认插画没有被题目卡片遮住，也没有重要内容被裁切。
3. 查看文件体积，并在普通校园网络下测试首次加载。
4. 确认背景中没有必须让学生读懂的信息。
