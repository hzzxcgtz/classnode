# ClassNode 内置音色试听

2026-10-31 使用维护者令牌统一生成的 218 个扣子系统音色，不包含个人自定义音色或访问令牌。MP3 合计约 13 MB。已验证完整解码、正时长、文件大小与 SHA-256。

- `manifest.json`：音色 ID、名称、语言、试听文案、文件大小、哈希和时长。
- `audio/<voice-id>.mp3`：对应音色的试听文件。
- 10 个限定语种音色使用英文、越南语或泰语文案，其余使用中文文案。

桌面运行时保持本目录相对服务根目录的 `assets/voice-previews/` 路径。新增生成文件写入用户数据目录的 `voice-previews/`，不要写回这里，也不要将用户缓存打进发行包。
