# 更新日志

## [1.6.1] — 2026-07-28

### 新增

- 教师端新增局域网访问开关，可随时允许或暂停学生设备连接
- 服务启动时自动检测新版本，发现更新后在教师端显示提醒
- 使用指南补充智能体接入、学生加入、课堂看板和历史导出等操作截图

### 优化

- 优化学生加入与身份查找流程，姓名检索、学生排序和移动端课堂界面更加稳定
- 优化智能体凭据编辑体验：新密钥输入时保持可见，已保存内容再次编辑时以脱敏形式显示，并可直接替换
- 优化课堂管理列表的互动码复制交互，使用更明确的复制图标和操作提示

### 修复

- 修复部分升级数据或分组课堂中学生身份关联异常，导致对话时提示“未找到学生记录”的问题
- 修复部分智能体 API Token、API Key 或 Secret 无法重新输入和保存的问题
- 修复屏蔽词启用或禁用后，操作提示出现在错误区域的问题
- 修复部分课堂参与者迁移、分组加入和消息同步场景中的数据一致性问题
