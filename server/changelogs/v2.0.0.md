# 更新日志

## [2.0.0] — 2026-09-29

2.0 重新设计了课堂的形态。

在此之前，一堂课的互动方式只有一种：学生和 AI 对话。现在课堂由三个模块组成——**学习单**、**探究空间**、**智能学伴**。教师在同一块看板上决定这三个模块什么时候开放、什么时候只做预告、什么时候收起。

### 学习单 · 当堂练习与检测

教师像出卷子一样编辑学习单，支持选择填空、单选、多选、判断、填空、排序、连线、归类、问答、绘图十种题型，可以分任务归类、逐题赋分。

学生逐题作答、逐题提交。教师在教室大屏上看到的不再只是“谁交了”，而是**每个人此刻正在写什么**——填的字、连的线、画的内容都会实时出现在对应的格子里。点开一个学生，看到他每一题的作答详情；点开一道题，看到全班的作答分布。

### 探究空间 · 动手体验原理

教师上传自己做的交互式网页（单个 HTML 文件，或 zip / rar / 7z 压缩包），学生在隔离的沙箱里打开、动手操作，不用离开课堂去访问外网。教师能看到每台设备正停在哪一步。

### 智能学伴 · AI 对话与分析

原有的 AI 对话保留下来，并新增了两处面向教师的分析入口：**对话分析**给出全班的高频词云与活跃度排行；**按题统计**按题型给出全班的作答分布、作答过程，问答题和绘图题还可以请智能体给出解读。

### 其他

- 高级模式下，每个小组可以分别指定自己的智能体与探究网页
- 学习单与探究空间的记录可以导出为报告，手写作答会渲染成图片一并保存
- 各平台的 API Token 集中管理，支持设置有效期与到期提醒
