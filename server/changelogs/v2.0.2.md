# 更新日志

## [2.0.2] — 2026-10-12

本次更新重新设计桌面控制窗口，完善服务启停与密码重置操作，并更新 2.0 系列的门户展示。

### 桌面控制窗口

- macOS 与 Windows 分别采用贴近各自系统的控件、字体、按钮和分组样式，保留系统原生标题栏。
- 教师端与学生端完整展示访问网址，打开和复制操作更清晰；教师端使用本机地址，学生端使用所选局域网地址。
- 新增学生访问网络切换、数据与日志目录入口，以及关闭窗口后的后台运行说明和退出服务确认。
- 启动失败时显示原因、日志入口和重试按钮；修正端口被其他程序占用时误判为服务运行的问题。

### 密码与网络管理

- 重置管理密码改为六位随机数字，支持一键复制及打开教师端登录；结果保留至手动关闭。
- 重置时撤销旧的教师会话并清除登录失败限制，新密码可立即用于登录。
- 窗口通过本机接口读取和保存网络配置，修正未登录教师端时无法保存网卡选择的问题；不可用的网卡地址会被拒绝。

### 升级说明

桌面控制窗口的更新需要安装新版安装包后生效。现有课堂数据与设置继续保留。
