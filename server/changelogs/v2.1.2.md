# 更新日志

## [2.1.2] — 2026-10-20

### 优化

- 优化学习单编辑布局：评分设置更紧凑，条目与分类框并列，连线和排序操作按钮与内容对齐。
- 任务要求与选项配图支持拖入上传，提供明确的投放提示，图片右上角可快速移除。
- 统一课堂设置中学习模块的控件尺寸，明确学习单固定状态及更换网页、学伴后的影响。
- 新建学习单默认使用支点博士奖励和清爽无图背景；未填写标题时保存为「未命名学习单」。
- 开启任务 AI 评分时默认启用学生自主评价，未设置评价次数时默认为 1 次。
- 优化任务开放方式、提交修改、AI 评价等教师端说明，统一学习单、主题和任务的称呼。

### 修复

- 桌面服务启动前识别并回收同一安装、当前用户的 ClassNode 残留服务；其他程序占用端口时保留提示，不自动终止。
- 修复 macOS 打包环境缺少新版图标工具时无法继续构建的问题，提供兼容图标回退。
