# 更新日志

## [2.1.2] — 2026-10-22

### 新增

- 历史课堂支持下载课堂资料包，包含可离线查看的网页、文字记录和相关附件，方便教师留存和交给其他工具分析；探究空间网页不纳入资料导出。
- 学习单数据导出为 Word 文档：完整的教师参考学习单与学生作答记录分开保存，保留参考答案、评分标准、作品和评价记录，学生记录不再重复题目。
- 历史课堂支持按关键词、班级、模块和日期筛选，并可调整时间排序。
- 学习单编辑页新增「撤销」「重做」按钮，支持恢复任务编辑操作。
- 学生和教师查看学生上传的图片时，支持向左、向右旋转 90°，调整后自动保存，并实时同步到相关学生端与教师看板。
- 教师可全屏展示学生的主观题评价与建议，支持调整字号，使用支点博士图标和称呼，并以彩色、灰色奖励图标直观呈现获得情况。
- AI 评分明细新增「查看本题作答」入口，可直接切换到对应学生，展开、滚动定位并聚焦当前小题。

### 优化

- 重新设计课堂资料包的网页查看界面，支持按学生、任务浏览，搜索记录、查看大图和打印，精简记录编号等技术信息。
- 优化导出 Word 的字体、标题层级、图片尺寸与分页，长篇作答和评价内容完整保留。
- 优化学习单编辑布局与统一间距，整合任务要求工具栏，收紧评分设置，调整分类、连线和排序操作区域。
- 任务要求与选项配图支持拖入上传，提供清晰的投放提示和图片移除操作。
- 新建学习单默认使用支点博士奖励和清爽无图背景；未填写标题时保存为「未命名学习单」。
- 开启任务 AI 评分时默认启用学生自主评价，未设置评价次数时默认为 1 次。
- 优化任务开放、提交修改、AI 评价等教师端说明，并统一课堂设置中的控件尺寸。
- 管理员密码重置改为直接输入并确认新密码，不再生成随机密码；重置后原密码与旧登录失效。
- 看板「指定」模式更名为「固定」，按课堂记住当前浏览器中的模式和所选模块，刷新后恢复原来的选择。
- 点击学生监控卡片后，作答抽屉默认展开卡片当前显示的题目，并滚动定位、聚焦该题。
- 用颜色区分任务「已分析」「未分析」等状态，缩小状态标签；增强评分明细的展开提示，调整全屏按钮、关闭按钮与图片操作工具栏。
- 学生智能学伴对话区移除内置语音输入按钮，可使用 iPad 等设备输入法自带的听写功能。
- 「提示词模板」更名为「分析提示词模板」。

### 修复

- 历史课堂列表不再只返回最近 50 堂课，避免较早的课堂无法查看。
- 桌面服务启动前识别并回收同一安装、当前用户的 ClassNode 残留服务；其他程序占用端口时保留提示，不自动终止。
- 修复 macOS 打包环境缺少新版图标工具时无法继续构建的问题，提供兼容图标回退。
- 修复教师端放大学生图片后无法拖动查看的问题，支持鼠标和触屏移动图片。
- 修复服务重启后首次点击「提示词模板」或「教师入口」无反应、需要再次点击的问题。
- 修复 Windows 构建中的题干通知传递测试误判，以及端口恢复检查超时和 PowerShell 数组解析兼容问题。
