# 更新日志

## [2.1.4] — 2026-10-24

### 新增

- 智能学伴支持学生直接录音并发送给扣子低代码智能体，支持语音消息播放，单次录音最长 5 分钟。
- 新增局域网 HTTPS 服务及 iPad 录音设置页，提供证书下载、安装引导、二维码入口与证书信息；教师电脑 IP 改变后自动更新服务证书，保留原有根证书。
- 图片、AI 评价与建议、智能学伴对话投屏的批注支持自动保存与重新打开恢复；新增保存状态、失败重试和多窗口更新冲突提示，批注独立于学生原作品保存。

### 优化

- 学生对话默认使用文字输入；可切换为按住说话，也可长按空白文字输入框录音，松开发送、上滑取消，并支持点按录音、发送失败后重试与删除。
- 文字输入框长按录音时，正常录音采用绿色提示，上滑后的“松开取消”采用红色提示与背景，滑回后恢复录音配色。
- 学生文字、语音与图片消息采用统一风格的蓝、绿、暖色消息框，与智能体回复保持区分；精简语音占位文字，改善音频播放器和图片预览布局。
- 移除本地静音检测模型及相关资源，音频内容交由扣子处理，减少模型初始化等待和设备负担；保留过短录音、录制失败、取消与设备中断处理。
- 扣子对话失败时，学生端显示便于理解的提示；本地日志保留流式错误码、具体原因和请求追踪信息，区分业务失败与响应流提前结束。通用错误不再直接显示为技术报错，也不据此推断音频一定为空白。
- iPad / iPhone 安装引导补充系统相机扫码、Safari 下载描述文件、手动前往设置安装及完全信任证书的步骤，并说明下载后超过 8 分钟未安装需重新下载。
- 录音设置页补充 Safari 当前网站的麦克风授权说明：在 HTTPS 课堂页面进入“网站设置”，将“麦克风”从“询问”改为“允许”，减少重复授权询问。
- 学习单“按任务查看”中的“全班 AI 评分明细”默认收拢，重新进入页面或切换任务后均恢复收拢状态，需要时手动展开。
- 精简学生照片作答的重复操作入口和评价历史中的重复作品展示，调整图片操作按钮与评价区域间距。

### 使用说明

- 网页录音需要 HTTPS 与浏览器麦克风权限。局域网根证书是否需要安装取决于设备对该证书的信任情况；更换根证书后需重新安装信任，麦克风授权需在实际课堂网站设置。
- 已录制的空白音频也可能上传并产生正常调用费用。录音内容、回答与具体失败原因以扣子实际处理结果为准。
- 迁移教师电脑时，请单独保留数据目录中的 `lan-https` 文件夹；课堂数据备份不包含该证书目录。
