# 更新日志

## [2.2.0] — 2026-11-04

### 分组课堂

- 分组模式和高级模式可选择小组登录或组员登录。小组登录共享学习资源，组员登录分别保存作答和对话，同组学生可在共享设备上快速切换。
- 教师看板按小组和学号组织学生。班级分组调整自动同步到进行中的课堂，保留已有作答和对话。

### AI 评价和智能学伴

- 学习单可配置最多三个个人评价智能体。按扣子令牌调度附件请求，每个令牌最多同时处理八项附件请求，纯文字请求直接发送。
- 智能学伴可配置多个对话智能体，首次对话分配后沿用同一智能体。智能体卡片显示令牌名称，便于区分不同账号的配置。
- 图片作答的个人评价返回精简的评价与建议。教师生成全班分析时使用压缩后的作答拼图。
- 修复停用某个学伴时其他可用学伴被一并锁定的问题，并恢复旧版非扣子分析智能体的个人评价兼容性。

### 拍照作答

- 优化照片上传前的压缩，优先采用 WebP。学习单支持引导拍照和裁剪，便于保留纸面作答区域。
