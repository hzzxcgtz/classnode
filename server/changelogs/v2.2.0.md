# 更新日志

## [2.2.0] — 2026-11-04

### 学习单课堂反馈

- 信息收集题新增「课堂反馈看板」，与「AI 分析看板」分开展示。选择、排序等题型可按题型查看选项分布或常见排序组合，并查看人数和比例。
- 文字收集题在生成全班分析时一并整理「观点云」。AI 合并意思相近的作答，优先提炼 4–6 条共同观点，最多 10 条。每条至少有两份作答支持，份数按实际作答名单去重统计。尚未分析时，会提示教师先生成全班分析。
- 观点云支持调整字号、切换份数显示和重新排布。看板和投屏中都可按住空白处拖动整组观点。悬停时当前观点放大，其余观点变淡。

### 分组课堂

- 分组模式和高级模式可选择小组登录或组员登录。小组登录共享学习资源，组员登录分别保存作答和对话，同组学生可在共享设备上快速切换。
- 组员登录时先选小组，再选姓名。名单显示头像和学号，班级人数较多时可按姓氏筛选或搜索姓名。
- 教师看板按小组和学号组织学生，用浅色区分小组。班级分组调整自动同步到进行中的课堂，保留已有作答和对话。课堂工具栏和筛选栏也更紧凑，为学生卡片留出更多空间。

### AI 评价和智能学伴

- 学习单评价和智能学伴均可从一个智能体起步，按需添加到最多三个。可用不同扣子账号分担请求，选择列表和智能体卡片显示令牌名称，便于区分同名智能体。
- 个人评价和智能学伴的附件请求按扣子令牌排队，每个令牌最多同时处理八项附件请求。纯文字请求直接发送。智能学伴在学生首次发消息时分配智能体，后续对话沿用同一个。
- 图片作答的个人评价返回精简的评价与建议。教师发起全班分析时，图片作答可按压缩拼图分批处理，纯语音作答可按录音分批处理。配置了不同扣子账号时，最多由两个智能体分担批次，再由主智能体汇总。
- 修复停用某个学伴时其他可用学伴被一并锁定的问题，并恢复旧版非扣子分析智能体的个人评价兼容性。

### 拍照作答

- 优化照片上传前的压缩，优先采用 WebP。学习单支持引导拍照、自动查找纸张边缘和手动调整四角，可预览裁切效果后上传，也可使用原图。
