# 更新日志

## [2.2.5] — 2026-11-12

### 填空题答案组合

- 支持为同一道填空题设置多组完整的正确答案，适用于左右互换、顺序不唯一等情况。系统按得分最高的一整组判分，避免混用不同组合的答案。
- 答案组合使用表格设置：有选词的空通过下拉列表选择，手工填写的空可设置多个可接受答案。支持逐空计分和整题计分。
- 新增、删除或移动填空时，组合答案跟随对应空位保留。学生订正、教师查看、导出参考答案和全班分析同步使用组合规则。
- 精简判分提示与设置入口，保留原有单空联动作为高级设置。

### 学习单编辑与查看

- 主题标题可设为隐藏，主题和任务的删除入口移至左侧结构列表，悬停时显示。
- 编辑预览支持整页查看和翻页查看。教师查看学生学习单时，可通过左右滑动、切换按钮或任务列表翻页，中间页突出展示，两侧页面淡化。
- 优化查看弹窗的宽度、遮罩及翻页效果，保留切换页面时的查看状态。

### 语音作答查看

- 观点云相关作答、教师作答详情等位置支持在已开启语音转文字时使用转写功能。
- 当前作答与评价记录为同一段录音时，避免重复显示播放条；历史录音仍可分别查看。
