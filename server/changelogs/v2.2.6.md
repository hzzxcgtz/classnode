# 更新日志

## [2.2.6] — 2026-11-19

### 评价题与课堂反馈

- 新增独立评价题，支持一至三级评价维度、可调评价上限及必填文字感想；评价图标跟随学习单设置。
- 提交前校验所有末级维度和最少字数，优化手机端评价操作、结果卡片与分布统计。
- 观点云按提及人数展示前十条，全部观点列表保留单人观点及原始作答依据；优化观点表述和分批分析。
- 为已有作答的量表变更增加保护，避免旧星级从统计和导出中消失；修复局域网 HTTP 下新增维度的问题。
- 作答更新后仍可查看上次观点云分析所用的作答，并提示教师重新生成分析。

### 课堂管理与身份选择

- 名单管理支持临时停用与恢复学生，停用后从身份选择和课堂看板中隐藏，当前人数同步更新；恢复后继续使用原身份，保留分组与课堂历史。
- 课堂列表新增清空数据入口，确认后清除作答、对话、分析等活动记录，保留课堂和教学材料配置。
- 清空课堂数据改用统一确认弹窗，分区说明清除与保留的内容，明确提示不可撤销及学生需重新选择姓名。
- 名单管理与姓名选择支持拼音首字母检索，姓名选择提供首字母筛选，统一头像、姓名、学号的对齐及滚动条间距。
- 优化创建课堂页面的分区、表单与底部操作栏，压缩参与模式卡片、统一图标和选中状态；显示已设置的班级图标，改善手机端长班名与状态标签布局。
- 已停用学生在学习单作答矩阵中隐藏，已保存的作答仍保留；补录到班级的学生同步加入对应的进行中课堂。

### 探究空间

- 支持添加已发布的 HTTPS 应用链接，可关联到课堂或在高级模式中按组配置。
- 教师和学生均在新标签页打开外部应用，原课堂页面保留；上传的 HTML 和网页压缩包继续在课堂内打开。

### 学习单导航与状态显示

- 新增侧边浮动目录，使用小题编号与题型别称快速跳转，显示当前位置、完成状态及解锁提示。
- 手机端目录默认收拢，平板和电脑默认展开；支持手动折叠到右侧窄条，长目录独立滚动。
- 题型别称调整为“思辨判断”“巧思填空”“评价反馈”，与导出内容同步。
- 不计分任务不再显示待评分奖励图标；整张学习单不涉及奖励时，隐藏学生卡片和学生端顶部的奖励累计。

### 编辑与查看体验

- 链接可手工选择统一风格的彩色附件图标，采用下划线和打开箭头提示可点击；编辑页与阅读页同步显示，补充手机端新标签打开处理。
- 维度编辑共用格式工具栏，文字颜色支持最近使用记录，优化链接光标、翻页预览、图文题透明度和手机布局。
- 主题说明改为左对齐、段首缩进，优化评价表头对齐、图标间距和感想说明字号；“必填／选填”提示统一为浅底无边框标签。
- 统一课堂操作按钮及设置下拉框的尺寸，调整停用图标，精简重复提示，完善回归测试与类型检查。
- 全面统一学习单创建与编辑页面各题型的文字、题头、字段标签、表单尺寸与操作名称，修复手机端题型名称挤压及窄屏横向溢出。
- 修复判断题与排序题在调查收集模式下仍显示正确答案设置的问题；切回练习判分时保留原答案，统一各题型的用途和个人 AI 评价说明。
- 绘图与图文编辑的移除操作改用统一确认弹窗，支持键盘焦点约束和 Esc 取消；修复局域网 HTTP 下添加填空答案组合的兼容问题。
- 增大“观点提炼要求”编辑框的默认高度，方便查看和修改长段要求。
- 移除评价上限旁重复的图标预览及提交按钮下的剩余项提示，继续保留提交前的完整性校验。
