## Review Focus

规格是**愿景文件**，它没说到的输入**不是**「可以崩」的许可。下面五条是规格隐含、而**最容易咬到人**的
输入 / 失效形态。前三条在下面的任务里配了用例；后两条本机**做不到**，如实进真机验收清单。

1. **「未作答」与「答了但清空」是两件事。** `WorksheetAnswer.value` 为 `null` 是**学生把这一题删干净了**
   （有那一行、`status` 是 `draft`），而**没有那一行**才是「未作答」。报告里两者必须**说不同的话**，
   否则「他没做」与「他做了又删了」在纸上长得一样。（用例：Task B1。）
2. **`InkValue` 的坏形状**（手工改过的库行 / 旧版本）：`readInkValue` 读不出来时必须收成
   **一句说明文字**，而不是抛、也不是画一张空白图。（用例：Task B1 + Task C1。）
3. **半对必须印成半对。** `isCorrect: false` **同时**覆盖「错」与「半对」（规格 §12）⇒
   只读 `isCorrect` 会把半对印成错。判据必须走 `gradeState`。（用例：Task B1，含反证。）
4. **一份 40 人班、每人多道手写题的导出**：文件多大、要等多久、Word 打不打得开。
   本机**没有 Word**，也没有能渲染它的环境 ⇒ 只能真机。进验收清单。
5. **`sharp` 拿不到时的降级**（规格 §2.6 / §3.4）：那一格必须印「（手写作答，本机无法渲染成图片）」，
   **不是**留空。要手工造那个环境才能验。进验收清单。

```ts
import assert from 'node:assert/strict';
import { strokePath as frontPath, strokeWidthPx as frontWidth } from './worksheet-ink.ts';
import { strokePath as backPath, strokeWidthPx as backWidth } from '../../server/src/services/ink-path.ts';

/** 一批刻意刁钻的笔画：单点 / 空 / 边界 0 与 1 / 会触发两位小数取整的坐标 / 多笔。 */
const BOXES = [
  { w: 320, h: 240 },
  { w: 0, h: 0 },      // 框还没量出来
  { w: 1, h: 1 },      // 极端窄
  { w: 1280, h: 720 },
];
const STROKES = [
  { color: '#111827', width: 0.5, points: [[0, 0] as const, [1, 1] as const] },
  { color: '#111827', width: 0.004, points: [[0.5, 0.5] as const] },            // 单点
  { color: '#111827', width: 0.3, points: [] },                                 // 空
  { color: '#111827', width: 0.12, points: [[1 / 3, 2 / 7] as const, [0.987654, 0.123456] as const] },
  { color: '#111827', width: 0.9, points: [[0, 0] as const, [0, 1] as const, [1, 1] as const, [1, 0] as const] },
];

      assert.equal(backPath(stroke.points, box), frontPath(stroke.points, box), `strokePath 不一致：${label}`);
      assert.equal(backWidth(stroke, box), frontWidth(stroke, box), `strokeWidthPx 不一致：${label}`);
    }

test('对拍不是空转：至少有一条笔画产出非空 d', () => {
  // 阳性对照 —— 少了它，两个实现**都回空串**也能让上面那条全绿。
  assert.notEqual(frontPath(STROKES[0].points, BOXES[0]), '');
});
```

```ts
import assert from 'node:assert/strict';
```

```ts
const ONE_STROKE = {
  format: 'ink/v1' as const,
  canvas: { w: 300, h: 200 },
  strokes: [{ color: '#111827', width: 0.2, points: [[0.1, 0.1], [0.9, 0.9]] as Array<[number, number]> }],
};

test('★ 一笔画 ⇒ 一张非空的 PNG，且长宽都不超过上限', async () => {
  const png = await inkToPng(ONE_STROKE);
  assert.ok(png, 'sharp 在测试环境里应当可用（它是 server 的依赖）');
  // PNG 的魔数：89 50 4E 47
  assert.deepEqual([...png.subarray(0, 4)], [0x89, 0x50, 0x4e, 0x47]);
  // 宽高在 IHDR 里（大端，偏移 16 / 20）
  const w = png.readUInt32BE(16);
  const h = png.readUInt32BE(20);
  assert.ok(w > 0 && w <= 400, `宽 ${w} 越界`);
  assert.ok(h > 0 && h <= 400, `高 ${h} 越界`);

test('画布框是 0×0（框还没量出来）⇒ 也要出图，不许回 null', async () => {
```
