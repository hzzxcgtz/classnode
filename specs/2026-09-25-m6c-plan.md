> 步骤用 `- [ ]` 复选框跟踪。

**Goal**：在 `/teacher/history/` 的「课堂记录」表里加**三列**，让教师一眼看到每节历史课的**三件套使用痕迹**。

**Architecture**：**一条聚合 + 三个字段 + 三列**。服务端在既有的 `/history/all` 那条原生 SQL 旁边
**再加两条**（同一个 `classroomId IN (…)` 形状，一次查完 50 个课堂）；类型加四个字段；
前端加三列，时长文案**复用 M6a 的 `formatDuration`**（不在前端另写一份）。

**Tech Stack**：Express + Prisma/SQLite · Next.js 15 前端 · Node 内置 test runner。

**规格**：`specs/2026-09-25-m6c-history-traces.md`（**权威**；本计划若与它冲突，以规格为准并当场报告冲突）。

## Global Constraints

**1–32 逐字沿用之前那几份计划**（`specs/2026-09-25-m6a-plan.md` 的 1–32 是编号权威）。
本计划只新增 **33–35**：

33. 🔴 **「探究空间 = 0 行」的文案不许写「未使用」**。库里两种成因**不可区分**（这节课确实没人用 /
    这节课没有教师打开过看板 ⇒ 学生按需推流根本没推 —— `recordWebappSummary` 的注释逐字写着，
    而它「空 drain 时连删都不做」正是因为这个）。**只能写「无记录」。**
34. 🔴 **学习单那一列的分母是「已有作答行数」，不是「参与者 × 题数」** ⇒ 文案只能写
    「已交 N / M 题」，**不许**写「已交 N/M 人」。
35. ⚠️ **一轮聚合查完 50 个课堂**，**不许 N+1**（照既有那条 `$queryRawUnsafe` 的形状）。

## Review Focus

1. **空表**：一节从没人用过探究空间、也从没人作答过的课 ⇒ 两个数都必须是 `0`，而**导出/查询不许报错**。
2. **多课堂一次查完**：50 条历史记录时，SQL 的 `IN (...)` 占位符数量必须与 id 数量一致
   （既有那条已经这么写，新加的必须同形）。
3. **恢复课堂再结束** ⇒ `WebappUsage` 被**替换**（不是累加）⇒ 历史页看到的是最后一次的快照。
4. **三列挤不挤得下** —— 本机**验不了**（无浏览器驱动）。进验收清单。
5. **「无记录」会不会被读成「没用过」** —— 只能真机看教师怎么读它。

在 `server/src/routes/classroom.ts` 里，**紧跟既有那条 `Message` 聚合之后**加：

```ts
export async function loadHistoryTraces(prisma: PrismaClient, ids: string[]) {
  const out = new Map<string, { webappUsageCount: number; webappDurationMs: number; worksheetSubmitted: number; worksheetTotal: number }>();
  if (ids.length === 0) return out;   // 与既有那条同一条守卫：空数组不发查询
  const placeholders = ids.map(() => '?').join(',');
  // ⚠️ 两条聚合共用同一组占位符 —— 与既有那条 `Message` 聚合**同形**（GC 35）。
  const webapp = await prisma.$queryRawUnsafe<Array<{ classroomId: string; cnt: number; total: number }>>(
    `SELECT "classroomId", COUNT(*) AS cnt, COALESCE(SUM("durationMs"), 0) AS total FROM "WebappUsage" WHERE "classroomId" IN (${placeholders}) GROUP BY "classroomId"`,
    ...ids,
  );
  const worksheet = await prisma.$queryRawUnsafe<Array<{ classroomId: string; submitted: number; total: number }>>(
    `SELECT r."classroomId" AS "classroomId", SUM(CASE WHEN a."status" = 'submitted' THEN 1 ELSE 0 END) AS submitted, COUNT(*) AS total FROM "WorksheetAnswer" a JOIN "WorksheetResponse" r ON r."id" = a."responseId" WHERE r."classroomId" IN (${placeholders}) GROUP BY r."classroomId"`,
    ...ids,
  );
  for (const id of ids) out.set(id, { webappUsageCount: 0, webappDurationMs: 0, worksheetSubmitted: 0, worksheetTotal: 0 });
  for (const row of webapp) {
    const entry = out.get(row.classroomId);
    if (entry) { entry.webappUsageCount = Number(row.cnt); entry.webappDurationMs = Number(row.total); }
  }
  for (const row of worksheet) {
    const entry = out.get(row.classroomId);
    if (entry) { entry.worksheetSubmitted = Number(row.submitted); entry.worksheetTotal = Number(row.total); }
  }
  return out;
}
```

然后在 `result` 的 `map` 里带上这四个字段（照现有那几个字段的形状），并把
`ClassroomHistoryItem`（`src/lib/types.ts:662`）加上四个 `number` 字段。
