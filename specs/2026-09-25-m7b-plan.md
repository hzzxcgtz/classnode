# M7b · 分析型智能体（把 M7a 那道缝接活）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 M7a 那个**故意禁用的**「发给 AI 分析」按钮接活 —— 教师先看见「本次将发什么」再确认，内容发给**学习单上指定的**那个分析型智能体，解读写回 `narrative`。

**Architecture:** 四层。① **闸**（`agent-purpose.ts`，零 import）：哪些智能体对**学生**可见 —— 两个调用点都走它；② **编排**（`analysis-agent.ts`，纯函数 + 薄编排）：载荷 → 消息、平台能力闸门、解读归一化；③ **外发**（`ai-proxy.ts` 新增的一个导出，**全仓唯一一处 `fetch` 到第三方**）；④ **端点与界面**（`run` 端点 + 浮层的预览/确认/显示）。

**Tech Stack:** Express + Prisma/SQLite（ESM）· Next.js 15 静态导出 + React 19（教师端）· 已有平台适配（Coze / 文心 / 智谱）· Node 内置测试运行器（**没有 vitest / jsdom**）。

**Spec:** `specs/2026-09-25-m7b-analysis-agent.md`（权威；用户已复核，四条裁定见其 §七）

## Global Constraints

- 🔴 **这是本项目第一次把学生的作业内容发出去。** 四条纪律：**单一外发点** · 每次发前预览确认 · **全程伪名** · **联系表不落盘**（`/uploads` 是 `express.static` 公开目录，落盘 = 全班的画能被 URL 取到）。
- 🔴 **只有 `coze` 收得了图**（`coze-agent`/`wenxin`/`zhipuai` 都不行，各有逐字证据）。有图而平台不是 `coze` ⇒ **响亮拒绝**，不是悄悄只发文档。
- 🔴 **不走 anonymizer**：分析是班级级的、没有「那个学生」；载荷已经是伪名。传假名字会污染匿名映射表（`MAX_ENTRIES = 500` 重置会换掉进行中聊天的伪名）。
- 🔴 **学生端只见 tutoring**：过滤点**至少两处**（HTTP 首屏 `routes/classroom.ts:1085`、socket 的 `joined` 载荷 `socket/index.ts:1151`）⇒ 抽**共用**助手，两处都走它。
- 🔴 **两组字段各自动自己那一半**：`run` 端点只写 `narrative`/`agentId`/`model`，**一个 `aggregate`/`totalCount`/`computedAt` 都不许碰**。
- **`Agent` 是已发布的表** ⇒ 加列走启动期的 `PRAGMA` + `ALTER TABLE … NOT NULL DEFAULT 'tutoring'`（有默认值，SQLite 允许）—— 同 `index.ts:352` 那几条的写法。
- **本机没有浏览器驱动、没有 jsdom**（实测零命中）⇒ 界面一条都验不了；真模型也没有。
- **本仓的 `grep` 是转发给 ugrep 的 wrapper** ⇒ 搜源码用 `/usr/bin/grep`。
- **`pnpm build` 里的 Safari 15 闸门**会扫 `src/lib` 与 `src/app/classroom`（本批的 `http-error.ts` 式零 import 模块若落在 `src/lib` 要守同一套约束）。

## Review Focus

下面是本设计**必然要遇到、而每个任务自己的用例不会自动覆盖**的五类情形，按「最可能咬到人」排序。
每一条都在它所属任务的步骤里配了用例。

1. **教师在解析一篇写得很差的作文**：模型返回的是**废话或空**（不是报错）⇒ 不能把 `narrative` 写成空串或废话，**要么不写、要么如实存**；已有的解读**绝不能被清空**。教师最可能踩的就是它。
2. **同一份学习单被两个班用**（M7a 已经踩过一次）：分析是**按课堂**存的 ⇒ `run` 端点必须带 `classroomId` 且校验，不然会在乙班重发甲班的内容。
3. **载荷里一条内容都没有**（全班没交，`covered === 0`）⇒ 发一个空载荷给模型是**纯浪费**且会得到一段编造的解读 ⇒ 应当**在闸门处拒绝**（「还没有已提交的作答」）。
4. **平台收不了图而教师点了确认**：闸门在**发之前**就该拦下；即使拦漏了，`proxyAnalysisRequest` 也必须**不发起请求**就失败（第二道）。
5. **模型返回超长**（几千字的排比句）⇒ 截断并**标注**（与 M7a 的 `ANSWER_TEXT_MAX` 同一条纪律），不能悄悄砍也不能原样入库。

`server/src/services/agent-purpose.ts`：

```ts
/**
 * ★ M7b：**「这个智能体学生能不能看见」这门闸**。
 *
 * 🔴 **本文件一个 import 都没有** —— 与 `analysis-gate.ts` / `question-type-labels.ts` 同一条理由：
 * 前端用例用 `node --test` 直接跑 TS 源，而任何 import 都会让跨工程加载失败（M6a 栽过两次）。
 * ⇒ 实施者：**不要**在这里 import Prisma 的类型，用结构化的入参类型。
 *
 * 🔴 为什么 `purpose` 是**一门闸**而不是标签：学生端的智能体列表来自 `ClassroomAgent`，
 * 而服务端今天只读 `agent.enabled`（`routes/classroom.ts:1090`）⇒ 加了分析型之后，
 * 教师可以把它选成学伴，**它就会出现在小学生的聊天列表里** ——
 * 一个「会收到全班作业」的 bot。设计文档 §15.1 那条配套调整正是为此。
 */

export const AGENT_PURPOSES = ['tutoring', 'analysis'] as const;
export type AgentPurpose = (typeof AGENT_PURPOSES)[number];

/**
 * 归一化。**坏值一律回落 `'tutoring'`**（与 `normalizePointValue` / `normalizeAnalysisKnobs`
 * 同一条纪律：一个手改坏的值不该让教师存不进去）。
 * ⚠️ 回落方向是**保守的**：`tutoring` 会被学生看见 —— 而 `analysis` 是**加了闸**的那一侧。
 * 反过来的话，一个坏值会让一个本该当学伴的 bot 从学生眼前消失（**静默**）。
 */
export function normalizeAgentPurpose(raw: unknown): AgentPurpose {
  return raw === 'analysis' ? 'analysis' : 'tutoring';
}

/**
 * 学生端那一份视图（两处调用点**共用同一个构造**，否则首屏与 socket 会分叉）。
 *
 * ⚠️ 判据是「**不是** `analysis`」而不是「`=== 'tutoring'`」：后者会把
 * **缺字段的行**（`purpose` 列刚加上的旧行、或手改过的行）整个吞掉 ——
 * 那些 bot 本来就是学伴，让学生看不见它们是**静默的功能损失**。
 *
 * ⚠️ 这里**刻意没有**一个 `studentVisibleAgents(rows)` 的「过滤」助手：本任务里
 * 两处调用点都是「map 成视图 + 丢掉 null」，多一个只被用例调用的导出就是一件
 * **装饰品**（本项目栽过：`unmappedParticipantsNotice` 有定义、有用例、没人调用）。
 */
export function studentAgentView(row: {
  agent: {
    id: string; name: string; logo: string | null; platform: string;
    enabled: boolean; greeting?: string | null; purpose?: unknown;
  };
}): { id: string; name: string; logo: string | null; platform: string; enabled: boolean; greeting: string | null } | null {
  const { agent } = row;
  if (agent.purpose === 'analysis') return null;
  return {
    id: agent.id,
    name: agent.name,
    logo: agent.logo,
    platform: agent.platform,
    enabled: agent.enabled,
    greeting: agent.greeting ?? null,
  };
}
```

import type { AnalysisPayload } from './analysis-payload.js';

/**
 * ★ M7b：编排层。**不碰网络** —— 真正发出去的那一次在 `ai-proxy.ts` 的
 * `proxyAnalysisRequest`（全仓唯一一处 fetch 到第三方，见规格 §3.3）。
 *
 * 本文件里的三个函数是**纯的**，因此本机可测 —— 而「真模型返回什么」本机永远验不了
 * （没有可调用的平台/密钥），所以能验的全部价值都在这里。
 */

/** 一份**能收图**的平台清单。实测依据写在规格 §2.1（每一条都有逐字出处）。 */
export const IMAGE_CAPABLE_PLATFORMS: readonly string[] = ['coze'];

/** 解读的长度上限。与 M7a 的 `ANSWER_TEXT_MAX` 同一条纪律：截断要**说出来**。 */
export const NARRATIVE_MAX = 4000;

/**
 * 归一化模型的返回。**空白与坏值一律回空串** —— 而调用方见到空串就**不写库**：
 * 把 `narrative` 写成空串的后果是「界面上原本那段解读消失了」，而**没有任何报错**。
 */
export function normalizeNarrative(raw: unknown): string {
  if (typeof raw !== 'string') return '';
  const trimmed = raw.trim();
  if (trimmed === '') return '';
  if (trimmed.length <= NARRATIVE_MAX) return trimmed;
  return `${trimmed.slice(0, NARRATIVE_MAX)}\n（已截断：原文共 ${trimmed.length} 字，只保留前 ${NARRATIVE_MAX} 字）`;
}

/** 发之前的两道闸里的**第一道**（第二道在 `proxyAnalysisRequest` 里）。 */
export function analysisGateOf(
  payload: { covered: number; payloadKind: 'text' | 'image' | 'mixed' }, platform: string,
): { ok: true } | { ok: false; reason: string } {
  if (payload.covered === 0) {
    return { ok: false, reason: '这道题还没有已提交的作答 —— 发一个空载荷只会得到一段编造的解读。' };
  }
  const hasImage = payload.payloadKind === 'image' || payload.payloadKind === 'mixed';
  if (hasImage && !IMAGE_CAPABLE_PLATFORMS.includes(platform)) {
    return {
      ok: false,
      reason: `当前平台的智能体（${platform}）**收不了图** —— 这份载荷里有手写/绘图内容。`
        + '请在学习单里改用一个 **Coze** 平台的分析型智能体。',
    };
  }
  return { ok: true };
}

/** 固定引导语（进代码）。具体要什么口径由教师写在平台的提示词里（规格 §3.7）。 */
const LEAD = '请分析下面这份全班作答，指出典型错误与共同困难。';

/**
 * 载荷 → 发给模型的那段文本。
 * ⚠️ **它已经是伪名**（M7a 的 `buildAnalysisPayload` 给的）—— 这里不许再去查真名，
 * 也不经过 `anonymizer`（规格 §2.3：那会往映射表里塞一条不是学生的记录）。
 */
export function buildAnalysisMessage(payload: AnalysisPayload): string {
  const head = [
    LEAD,
    '',
    `【题目】${payload.questionLabel} · ${payload.typeLabel}`,
    `题干：${payload.prompt || '（题干为空）'}`,
    `已交 ${payload.covered}/${payload.total}`,
    '',
  ].join('\n');
  if (payload.payloadKind === 'text') return `${head}【全班作答（均为代号）】\n${payload.text ?? ''}`;
  const sheets = payload.sheetLayouts.length;
  const shape = payload.knobs;
  const note = [
    `【附带】${sheets} 张联系表（手写/绘图作答拼成的图），`
      + `每张 ${shape.columns} 列、每格 ${shape.cellWidth}×${shape.cellHeight} 像素，`
      + '每格上方标着该学生的代号。',
    '⚠️ 图上凡有「（空白）」的格子表示那一份没有笔画；「（形状认不出）」表示那一份本版解析不了。',
  ].join('\n');
  // `mixed` 时文档与图都要给（文字那几条只存在于文档里）
  return payload.text ? `${head}${note}\n\n【文字作答（均为代号）】\n${payload.text}` : `${head}${note}`;
}

```ts
/**
 * ★ M7b：**分析型的唯一外发点**（全仓只有这一处把学生作业发出去）。
 * 规格 §3.3 立这条规矩的理由：将来的合规审查只看这一个函数。
 *
 * 与 `proxyAIRequest` 的**三处刻意的不同**（少一处都会出问题）：
 *
 * 1. 🔴 **不过 `anonymizer`**。载荷已经是伪名（M7a 的 `payloadLabels`），而分析是**班级级**的、
 *    没有「那个学生」可脱敏。传一个假名字会往映射表里塞一条**不是学生**的记录 ——
 *    而 `MAX_ENTRIES = 500`，塞满会**重置**，重置会换掉**正在进行的一段聊天**里
 *    同一个学生的伪名（`anonymizer.ts:7`）。
 * 2. 🔴 **收 `images: Buffer[]` 而不是 `fileUrls: string[]`**。既有那条路每个 url 都过
 *    `resolveLocalPath`（「仅允许读取应用上传目录中的文件」）⇒ 图必须先落盘到 `/uploads/`，
 *    而那是 `express.static` **公开目录** ⇒ 全班的画会变成一个**能被 URL 取到**的地址。
 *    这里走 `uploadBuffer`，**一个字节都不落盘**。
 * 3. 🔴 **平台闸门**：有图而平台不是 `coze` ⇒ 立刻回失败。这是第二道 ——
 *    第一道是 `analysis-agent.ts` 的 `analysisGateOf`（界面在发之前就用它拦下）。
 */
export async function proxyAnalysisRequest(
  agent: AgentConfig,
  message: string,
  images: Buffer[],
): Promise<{ success: boolean; content?: string; error?: string }> {
  if (images.length > 0 && agent.platform !== 'coze') {
    return {
      success: false,
      error: `当前平台的智能体（${agent.platform}）收不了图，请改用 Coze 平台的分析型智能体`,
    };
  }
  // ⚠️ 这里**刻意不调** `anonymizer.anonymize(...)` —— 见上面第 1 条。
  if (agent.platform !== 'coze') {
    // 文心 / 智谱那两条非流式分支的入参里有 `anonymizer` 相关的东西（`:119`-`:120`），
    // 复用它们就得先把脱敏拆出来 —— 而**无图时的文字分析**本版暂不做（见规格 §一 的范围：
    // 绘图题才是 §15.2 的重点，而它只有 coze 走得通）。
    return { success: false, error: `暂不支持的分析平台：${agent.platform}` };
  }
  try {
    const coze = createCozeBot(agent);
    const history: EnterMessage[] = [];
    if (images.length > 0) {
      const items: CozeMultimodalItem[] = [{ type: 'text', text: message }];
      for (const [index, buffer] of images.entries()) {
        const file = await coze.file.uploadBuffer(buffer, `analysis-${index}.png`);
        items.push({ type: 'image', file_id: file.id });
      }
      history.push({
        role: 'user',
        type: 'question',
        content: JSON.stringify(items),
        content_type: 'object_string',
      });
    }
    // 🔴 有图时第一个参数传**空串**，不是 `message`：`chat()` 见到 history 末尾已经是
    // `user` 消息就**不再追加** content（`coze-bot/index.ts:108-115` 逐字），
    // 而文字已经在 `object_string` 里了 —— 传 `message` 会让它重复一遍
    // （`proxyCoze` 那一支正是靠这个机制避免重复的）。
    //

/**
 * ★ M7b：把 M7a 那道缝接活 —— 读已存的载荷，发给学习单上指定的分析型智能体，写回解读。
 *

 * `aggregate`/`totalCount`/`computedAt` 属于「这份载荷是什么时候、按什么算的」，
 * 与「AI 怎么解读它」是两件事 —— 教师只想重发一次时不该连带把前者也改掉。
 */
router.post('/:id/analysis/:questionId/run', async (req, res) => {
  try {
    const prisma: PrismaClient = req.app.get('prisma');
    const worksheetId = req.params.id;
    const questionId = req.params.questionId;
    const classroomId = readClassroomIdQuery(req.query.classroomId);
    if (!classroomId) return res.status(400).json({ error: '缺少 classroomId' });

    const target = await loadAnalysisTarget(prisma, classroomId, worksheetId, questionId);
    if (!target.ok) return res.status(target.status).json({ error: target.error });

    const row = await prisma.worksheetQuestionAnalysis.findUnique({
      where: { classroomId_worksheetId_questionId: { classroomId, worksheetId, questionId } },
    });
    if (!row) return res.status(404).json({ error: '这道题还没有生成过分析' });

    // 学习单上指定的那个分析智能体（M7b 裁定 4：学习单级）
    const worksheet = await prisma.worksheet.findUnique({
      where: { id: worksheetId }, select: { settings: true },
    });
    const settings = normalizeSettings((worksheet?.settings ?? {}) as Record<string, unknown>);
    const agentId = settings.analysisAgentId;
    if (!agentId) {
      return res.status(400).json({ error: '这份学习单还没有指定分析型智能体（去学习单编辑器里选一个）' });
    }
    const agent = await prisma.agent.findUnique({ where: { id: agentId } });
    if (!agent || !agent.enabled) {
      return res.status(400).json({ error: '指定的分析型智能体不存在或已停用' });
    }

    const knobs = await loadAnalysisKnobs(prisma);
    const entries = entriesFromAggregate(row.aggregate);
    const payload = buildAnalysisPayload({
      question: { questionId, typeLabel: questionTypeLabel(target.node.type), prompt: target.node.prompt, index: target.index },
      entries, total: row.totalCount, knobs,
    });

    // 第一道闸（界面用的也是它）
    const gate = analysisGateOf(payload, agent.platform);
    if (!gate.ok) return res.status(400).json({ error: gate.reason });

    const message = buildAnalysisMessage(payload);
    // 联系表按需渲染（M7a 决定 1）—— 只有需要图时才渲
    const images: Buffer[] = [];
    if (payload.payloadKind !== 'text') {
      const rendered = await renderSheets(entries, payload.sheetLayouts, knobs);
      if (!rendered || rendered.sheets.length === 0) {
        return res.status(502).json({ error: '联系表渲不出来（本机缺图片渲染能力）' });
      }
      images.push(...rendered.sheets);
    }

    const result = await proxyAnalysisRequest(agent, message, images);
    if (!result.success) return res.status(502).json({ error: result.error ?? '分析失败' });
    const narrative = normalizeNarrative(result.content ?? '');
    if (narrative === '') {
      // 🔴 **空解读不写库** —— 写进去的后果是「界面上原本那段解读消失了」，而没有任何报错。
      return res.status(502).json({ error: '模型没有返回可用的解读（未写入）' });
    }

    await prisma.worksheetQuestionAnalysis.update({
      where: { classroomId_worksheetId_questionId: { classroomId, worksheetId, questionId } },
      // ⚠️ 只这三格。`aggregate`/`totalCount`/`computedAt` 一个字都不动。
      data: { narrative, agentId: agent.id, model: agent.platform },
    });
    res.json({ narrative, agentId: agent.id, model: agent.platform });
  } catch (error) {
    console.error('[worksheets] 分析失败:', error);
    res.status(500).json({ error: '分析失败' });
  }
});
```

/**
 * ★ M7b：**「本次将发什么」那几行** —— 用户裁定 3 的实现。
 *
 * 🔴 它是**承重的**：教师据此决定发不发。所以它值得一个纯模块 + 用例，
 * 而不是散在 JSX 里（本仓没有 jsdom ⇒ 散进 JSX 的判据**没有任何回归网**）。
 *
 * ⚠️ 量词走 `moduleCountUnit(mode)`（分组 / 高级模式下参与者是**组**）——
 * 本项目在「N 人 vs N 组」上被咬过两次，这里不许再写死「人」。
 */

/** 服务端 `payloadResponse` 给的那几样（只列要用到的）。 */
export interface AnalysisSendableSummary {
  covered: number;
  total: number;
  payloadKind: 'text' | 'image' | 'mixed';
  sheetCount: number;
  columns: number;
  cellWidth: number;
  cellHeight: number;
}

export function analysisPreviewLines(input: {
  agentName: string;
  platform: string;
  sendable: AnalysisSendableSummary;
  /** 「人」/「组」—— 由调用方用 `moduleCountUnit(mode)` 算好传进来。 */
  unit: string;
  /** 服务端 `canSend` 那一格：不能发时 `reason` 逐字说明。 */
  blockedReason?: string | null;
}): string[] {
  const { agentName, platform, sendable, unit, blockedReason } = input;
  const lines = [
    `发给：${agentName}（${platform}）`,
    sendable.payloadKind === 'text'
      ? '本次内容：一份聚合文档（全部是文字作答）'
      : `本次内容：${sendable.sheetCount} 张联系表`
        + `（${sendable.columns} 列 × 每格 ${sendable.cellWidth}×${sendable.cellHeight} 像素）`,
    `已交 ${sendable.covered}/${sendable.total} ${unit}`,
    '内容里一律是代号（User_001…），不含学生真实姓名',
    '⚠️ 第三方平台会留存这次对话（这是它的默认行为，本版没有关掉它）',
  ];
  if (sendable.payloadKind === 'mixed') {
    lines.push('⚠️ 本题有两种作答方式：文档与联系表各是一部分，**两样都会发出去**');
  }
  if (blockedReason) lines.push(`⚠️ ${blockedReason}`);
  return lines;
}
