## 🔴 三处点名的问题（有证据，不是印象）

### ① 每道题都有一条 4px 蓝竖条 —— **它不承载任何信息**

```css
.worksheet-editor-question {
  border: 1px solid #e2e8f0;
  border-left: 4px solid #2563eb;   /* ← 每张卡都有 */
  border-radius: 12px;
}
```

二十道题就是二十条蓝条。**左边框要承载状态才有意义**（比如「这题有错」/「正在编辑」），
而这里它是个常数 ⇒ 它只贡献噪声，还让整页看着「花」。
（对照：智能体卡片的左色条**承载启用/停用**，网页卡片的承载「被用过没有」——那两处是对的。）

### ② 没有间距节奏

同一个文件里三种圆角、七种内边距。所以整体「不齐」但又说不上哪不齐——
**这正是「丑」最常见的来源**：不是单个元素难看，是它们彼此的尺寸没有共同的刻度。

### ③ 顶栏浮在内容上方 8px，缝里露出页面底色

```css
.worksheet-editor-topbar { position: sticky; top: 8px; box-shadow: 0 6px 18px rgba(15,23,42,.06); }
```

滚动时它与下面第一张卡片之间**恒定露出一条 8px 的缝**，而缝里是底色 ——
它看起来像「没对齐」，而不是像「粘住了」。

## 设计方向（取值可直接用）

### 刻度：先定四个数，全页只用这四个

| 用途 | 值 |
|---|---|
| 间距 | **4 / 8 / 12 / 16 / 24**（只许用这五档；`14px` `18px` 这种一律并到最近的档） |
| 圆角 | **大块 12 · 控件 8 · 小标签 6**（三档，各司其职；现在那三种是随机的） |
| 字号 | 沿用现有（`0.688 / 0.75 / 0.813 / 0.938 / 1rem`）—— 这一层现在是齐的，别动 |
| 颜色 | 只保留**一个强调色**（`#2563eb`）+ 灰阶；见下 |

### ① 左竖条：**要么承载状态，要么去掉**

推荐**去掉**，改成「当前正在编辑的那一张」才亮（`:focus-within`）——
这样它就从噪声变成了**焦点指示**，而且零 JS。

> ⚠️ 若教师其实喜欢那条色条（它是这一页的「手感」），退路是**保留它但只给第一张/选中张**。
> 这条要问一句再定。

### ② 层次：三种「面」只该有三种

| 面 | 用在哪 | 取值 |
|---|---|---|
| 页面底 | 整页 | `#f8fafc` |
| 卡片 | 题目卡 / 顶栏 | `#fff` + `1px solid #e2e8f0` + `border-radius: 12` |
| 内嵌块 | 选项行 / 空 / 行内小框 | `#f8fafc` + `1px solid #eef2f6` + `border-radius: 8`，**不要阴影** |

**投影只给「浮起来的」东西**（顶栏、对话框、下拉）—— 现在卡片与浮层都有投影，于是**没有层次**。

### ③ 顶栏：`top: 0` + 覆盖式底边

`top: 8px` 那条缝去掉。要么贴死 `top: 0`，要么干脆**不 sticky**（内容不长时 sticky 只会添乱）。
⚠️ 它 `z-index: 20`，而**学生端的浮层是另一套坐标系** —— 这一页是教师端，改它不影响学生端。

### ④ 配色：把蓝色收回去

`#2563eb` 现在出现 6 次（竖条、主按钮、`.worksheet-editor-warn-hint`? …）。
**强调色只留给「可点的、当前生效的」**：主按钮、选中态、焦点环。
标题、标签、图标一律走灰阶（`#0f172a` / `#475569` / `#94a3b8`）。
—— 现在满页蓝，所以**没有一个地方是重点**。

## 硬约束（照着做，别踩）

1. 🔴 **类名一个都不许改、不许删。** 38 个类都在 `.tsx` 里被引用；改名字要动 11 个文件，
   而 JSX 那一层**本地验不了**。（本仓有 `css-module-class-reference.test.ts` 守**模块 CSS**，
   但 globals.css 的类名**没有网** —— 所以更要靠「不改名」这条纪律。）
2. 🔴 **Safari 15 门禁**：`scripts/check-classroom-browser-compat.mjs` **扫描 `src/app/globals.css`**。
   禁：lookbehind · `:has()` · `@container` · `content-visibility` · `color-mix(` · `Object.hasOwn` ·
   `structuredClone` · `.at(` · `findLast`。**`pnpm build` 会在违规时失败**，改完必须跑一次。
3. ⚠️ **`dvh` 有配额**：`worksheet.module.css` 的 `dvh` 用量被冻结在 3（那是学生端）。
   本页是教师端、在 `globals.css` 里，**但仍别引入 `dvh`** —— 配额规则查的是文件，不是语义。
4. ⚠️ **动效只碰 `transform` 与 `opacity`**，并在 `prefers-reduced-motion` 下降级
   （本仓对这一条有明确纪律，`shell.module.css` 的降级块是范例）。
5. ⚠️ **`color-mix(` 被禁** ⇒ 透明色**写死十六进制**（现有的 `#2563eb12` 这种写法可以继续用）。

## 验收（做完了看什么）

⚠️ **本地验不了**（无 jsdom、无浏览器）—— 机器能给的只有：`pnpm build` 过门禁、
`pnpm exec tsc --noEmit` 为 0、eslint 0 error。**样子只能教师看**。

机器能验的（**建议顺手加一条网**）：
- 一条源码扫描用例，断言 `globals.css` 里 `.worksheet-editor-*` **用到的圆角只有 3 种、
  间距只有那 5 档**。这类「刻度」是本仓反复栽的地方（改了不会红），而它**恰好可判定**。
  （先例：`css-module-animation.test.ts`、`allow-student-ask-direction.test.ts`。）

人工看（教师）：
1. 滚一遍二十道题的页面 —— **不再有一排蓝条**，视线能落在题干上。
2. 顶栏滚动时**不再露出那条缝**。
3. 满页扫过去，**蓝的只有「可点的、当前生效的」**。
4. 二十道题的卡片**上下左右间距一致**（不再有 14/16/18 混用）。

## 施工顺序

1. **只定刻度**：把圆角与间距按上表**归并**（纯替换，不改任何视觉「风格」）——
   这一步最便宜、风险最低，而且**做完就已经不「花」了**。跑一次 `pnpm build`。
2. **左竖条**（先问那一句：去掉还是只给选中张）。
3. **层次与投影**（三种面 + 投影只给浮层）。
4. **配色收敛**（蓝色只留强调用途）。
5. 顶栏那条缝。

> 每一步都可独立看、独立停 —— **第 1 步单独做完就已经是「重设计」的六成**，
> 因为「丑」的主因是刻度不齐，不是缺装饰。

## 一个仍未定的问题（问一句再动手）

写这份简报时问过、但**还没答**：

> 你说的「丑」主要是哪一类？　① 太密/太高　② 颜色花　③ 空、散、没重点　④ 整体没设计感

上面的方向是**按 ② + ④ 推的**（证据是那 6 处蓝与 3 种圆角）。
**如果其实是 ①（太密）**，那么第 1 步的刻度要整体**调小一档**、并且优先合并纵向间距，
而不是按现在这份取值走。
