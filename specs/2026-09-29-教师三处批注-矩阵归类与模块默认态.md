## 0. 现状（已核，别拿推断当依据）

### 0.1 ① 有一半已经存在，而且正是教师描述的那个形状

学生端学习单页**早就按任务分块**了：`groupAnswerable` / `studentVisibleGroups`
（`src/lib/worksheet-questions.ts`，2026-09-25 教师裁定），学生端面板已经在用
（`worksheet-panel.tsx:337` 的 `<h3>{group.title}</h3>`）。

⇒ ① 不是「做一个新东西」，是**把矩阵这一屏对齐到学生端已经有的那个形状**。
矩阵是最后一处还在「一行一道题、任务名重复 N 遍」的地方
（`worksheet-matrix.ts:115` 走的是 `flattenAnswerable`，行头画的是两级题号 `任务一：看一看 · 1`）。

### 0.2 ② 的 `preview` 今天同时是「新建默认」与「兜底态」

两个角色挂在**同一个常量**上：`server/src/services/classroom-module-state.ts:8`
的 `DEFAULT_MODULE_STATE = 'preview'`。它既是「新建课堂拿到什么」
（`POST /create` 不写 `ClassroomModule` 行 ⇒ `mergeModuleStates` 补齐成默认态），
也是「行缺失 / 脏数据时退回什么」（`mergeModuleStates` 第三参）。

⚠️ 两个角色的**方向相反**：新建要宽松（教师这次的要求就是「默认开放」），
脏数据要保守（一行手改坏的库不该把模块开给学生）。§2.1 因此**把它拆成两个常量**。

### 0.3 ③ 的现状数字确实不是「在线」

`moduleDistribution`（`page.tsx:1652`）逐 `students`（**全部参与者**）数
`resolveStudentFocus`，完全没看在不在线 ⇒ 截图里「离线 38 人」而「学习单 8 人」
（8 个里 6 个是离线、最后停在学习单的人）。

## 1. 矩阵按任务归类（图 1）

### 1.1 布局（教师选定那版预览的落地）

```
《0927测试》                       ← 块标题（不变）
卡住的是 任务一：看一看 · 1 · 8/40 人作答过   ← headline（不变）
┌──────────────────────────────────────────────────────┐
│ 任务一：看一看                            ← 段头行（占满整行、粘性左列）
├──────────────────────────────────────────────────────┤
│ 1  开心填空                     [分析]   │ ● ● ● …  │ 已交 8/40
│ 《望天门山》的作者是{填空域}代…           │           │
├──────────────────────────────────────────────────────┤
│ 2  慧眼选择                              │ ● ● ● …  │ 已交 3/40
│ 下面属于安徒生童话的作品有（ ）           │           │
├──────────────────────────────────────────────────────┤
│ 任务二：做一做                            ← 下一段
├──────────────────────────────────────────────────────┤
│ 1  真假侦探                              │ …        │
│ “一年之计在于春”这句话是说春…            │           │
└──────────────────────────────────────────────────────┘
```

- 段头行：`<th>` 粘性左列 + 一个 `colSpan` 填空格（**不是**给 `colSpan` 的 th 加 sticky ——
  那是没验证过的形状，而「粘性左列」在本文件里已经有一套跑通的写法）。
- 题行行头**两行**：第一行 `组内序号 + 别名`（右侧挂「分析」），第二行题干（最多 2 行，超出省略）。
- **`heading`（两级题号）不退场**：`matrixHeadline` 那句「卡住的是 任务一：看一看 · 1」
  仍然吃它。屏幕上不画它，是因为段头已经把任务说完了。

### 1.2 组内序号不许用下标推

`flattenAnswerable` 里散题用**跨全文**的计数器（`1` … `2`），任务内每段从 1 起。
⇒ `index + 1` 在散题那一段就是错的（会印出一个不存在的「1」）。
**序号由 `flattenAnswerable` 自己吐出来**（它本来就算到了那个 `counter.n`），
矩阵不许自己再推一遍 —— 与 `rowTally`「屏幕必须走用例断言的那个函数」同一条纪律。

### 1.3 落点

| 文件 | 改什么 |
|---|---|
| `src/lib/worksheet-questions.ts` | `AnswerableQuestion` += `label`（组内序号）；`flattenAnswerable` 填它 |
| `server/src/services/worksheet-heading.ts` | 镜像同步（那个文件的规矩是「逐字镜像」，含接口） |
| `src/app/teacher/classroom/worksheet-matrix.ts` | `MatrixRow` += `taskTitle` / `label`；`buildWorksheetMatrix` 走 `groupAnswerable`；新增纯函数 `matrixGroups(rows)` |
| `src/app/teacher/classroom/matrix-overlay.tsx` | 段头行 + 两行行头 + `questionTypeNickname` |

`matrixGroups`：把**连续**的、`taskTitle` 相同的行合成一组。
「连续」是有意的 —— 散题 A、任务一、散题 B 是三组（A 与 B 中间隔着一个任务），
与 `groupAnswerable` 里那条注释逐字同源。

### 1.4 别名只画在屏幕上，正式名仍在

`row.typeLabel`（`填空题`）**不删**，改挂在别名那个标签的 `title` 上（悬浮可见）。
`row.type` 仍是「分析」入口的判据（`isGradedType`），一个字不动。

## 2. 模块：新建即开放 + 预告 → 暂停（图 2）

### 2.1 拆常量：新建的初始态 ⊥ 兜底态

```ts
/** 新建课堂三个模块写进去的初始态（教师 2026-09-29：「创建后默认是开放」）。 */
export const INITIAL_MODULE_STATE: ModuleState = 'open';

/** 行缺失 / 脏数据时的兜底。**仍然是保守的 `preview`** —— 与上面那个不是一回事。 */
export const DEFAULT_MODULE_STATE: ModuleState = 'preview';
```

`POST /create` 与 `POST /create-advanced` 都在自己那个事务里写三行
（`modules: { create: initialModuleRows() }`）。**不改 `DEFAULT_MODULE_STATE`**，理由是
§0.2 那条：它是脏数据的兜底，而「把模块开给学生」不该是一次读失败的后果。

副作用（要说清）：新建课堂从此**有** `ClassroomModule` 行 ⇒
「本课堂未单独配置过模块」那条提示不会再出现在新课堂上（它本来就只在
`hasModuleRows === false` 时为真）。老课堂与恢复出来的库保持原状（仍是锁定态）。

### 2.2 预告 → 暂停

只改**中文标签**，`preview` 这个值一个字不动（改值 = 库 + API + 三份校验表一起动，
换不来任何功能）。⚠️ 语义随之偏了一点：`preview` 原来叫「预告」（即将开放），
现在叫「暂停」（本来能用、暂时不能）。两者靠同一句话活在同一个格子里：
**「这个模块是有的，但现在用不了」**。

| 位置 | 现在 | 改成 |
|---|---|---|
| `MODULE_STATE_LABELS.preview` | 预告 | **暂停** |
| `MODULE_STATE_HINTS.preview` | 学生可见但被锁定 | 学生看得见，暂时用不了 |
| `modulesNeverConfigured` 提示 | 以下三项均为默认的「预告」态 | 以下三项均为默认的「开放」态 |
| `classroom.ts:270` 的列注释 | `'open' \| 'preview' \| 'hidden'` | 不动（值没变） |

### 2.3 学生端文案（教师选定）

| 位置 | 现在 | 改成 |
|---|---|---|
| 首页卡片 CTA（`student-home.tsx`） | 未开放 | **稍后再来** |
| 首页卡片点它（toast） | 老师还没开放 | **这个模块还在的，老师先收起来啦，等一下再来看看～** |
| Tab 栏点它（`use-module-tabs.ts` 的 `openModule`） | 老师还没开放 | 同上 |
| 正用着被切走（同文件那个 effect） | 老师暂时关闭了这个模块，先回到首页 | **老师先把这个模块收起来了，我们待会儿再来～** |

⚠️ 三处都是**同一个事实**（`preview` 这一态的措辞），所以 §2.3 的表就是它的唯一清单；
改的时候 grep `老师还没开放` 而不是 grep 某一个文件（本仓「同一句话有多份拷贝」的旧账）。

`hidden` 那条路（`student-home.tsx` 的 `老师还没有开放今天的内容，先等等吧。`）**不动** ——
它答的是另一个问题（这个课堂一个模块都没有）。

## 3. 看板计数与筛选都改「在线」口径（图 3）

### 3.1 判据抽成纯模块

`src/app/teacher/classroom/board-module-counts.ts`（零 import，`node --test` 能跑）：

```ts
export type FocusModule = ModuleId | 'home' | 'unknown';
export function isOnlineStatus(status: string | undefined): boolean   // online | thinking
export function resolveFocus(focusMap, studentId): FocusModule         // 键不在 = unknown
export function onlineModuleDistribution(studentIds, focusMap, statuses): Record<FocusModule, number>
export function cardInOnlineModule(memberIds, module, focusMap, statuses): boolean
```

`page.tsx` 的 `resolveStudentFocus` 改成调 `resolveFocus`（**不是**抄一份），
`TileModule` 改成 `FocusModule` 的别名。

### 3.2 口径

- 三个模块格 = 「此刻**在线**（`online` 或 `thinking`）且实际待在这个模块」的**参与者**数；
- 点它筛出来的格子**同一口径**（成员里有人在线且在该模块即命中）——
  数字与格子不许各说各的；
- 「全部 / 需关注 / 离线」三格**不动**（教师的红框只圈了中间那三个）。

结果这一行是自洽的：`学习单 + 探究空间 + 智能学伴 + 首页 + 未知 = 在线人数`，
而 `在线 + 离线 = 全部`。截图那组数字会变成
`全部 40 │ 学习单 2 │ 探究空间 0 │ 智能学伴 0 │ 需关注 0 │ 离线 38`。

⚠️ 分组 / 高级模式下参与者是**组**，量词由 `moduleCountUnit` 给（既有口径，不动）。
