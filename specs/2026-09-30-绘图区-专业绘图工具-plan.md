# 绘图区 · 第二轮（专业绘图工具）施工计划

> 用 `superpowers:executing-plans` 逐任务执行。**任务的详细步骤沿用第一轮那份计划的体例**
>（`specs/2026-09-30-绘图区-基本图形工具-plan.md`）：每步「写用例 → 跑红 → 实现 → 跑绿 → 变异检验 → 提交」。

**Goal:** 把画布做成「像一个专业的绘图工具」：紧凑一行工具栏 + 弹出组 + 更好的图标 +
八色颜色 + 文本工具。

**Spec:** `specs/2026-09-30-绘图区-基本图形工具.md` 的「第二轮」那一节（**唯一依据**）

## Global Constraints

与第一轮**逐字相同**（见那份计划的同名一节）：零 import 的判据层 / 逐字镜像 + 对拍 /
不许 lookbehind 与那一串 API / 不许 `pnpm build` / 不许 `git add -A` / 每条断言做变异检验。

## Review Focus（这一轮最可能咬人的）

1. **`texts` 会不会在某一处被静默丢掉**（就是形状那轮 `shape` 的翻版 —— 两处逐字段重建）
2. **老数据（没有 `texts`）在十处照旧**
3. **文本的坐标与字号**：`at` 归一化、`size` 乘 `min(w,h)` —— 与笔迹同一条单位规则
4. **iPad 键盘**：打字时画布被盖住、光标看不见（**本机验不了**）
5. **颜色白名单**：八色都要能在 Word 导出里活下来

## Task 1: 颜色（判据 + 画布 + 工具栏）

**Files:** `src/lib/worksheet-ink.ts`(+镜像) / `ink-canvas.tsx` / `ink-body.tsx` / 各自的测试

- [ ] 判据层：`INK_PALETTE`（八个色值 + 中文名）、`INK_DEFAULT_COLOR`、`isInkColor`
- [ ] 用例：八色；默认 = 原来的 `INK_STROKE_COLOR`（**加选项不改默认**）
- [ ] 画布：新笔画用当前色；**选中元素后再点颜色 ⇒ 改那个元素的颜色**
- [ ] 工具栏：色板（当前色显示在按钮上）
- [ ] 变异检验 + 提交

## Task 2: 工具栏重做（一行 + 三个弹出组）

**Files:** `ink-body.tsx` / 一个新组件文件（弹出组）/ 测试

- [ ] 一行七个按钮：手写 / 图形▾ / T / 选择 ｜ 粗细▾ 颜色▾ ｜ 撤销 清空
- [ ] 三个弹出组：九宫格 / 三档 / 八色；点外面与 Esc 关掉（照编辑页那个颜色下拉的既有做法）
- [ ] **按钮上显示当前值**（当前图形图标 / 当前色块 / 当前粗细圆点）
- [ ] 图标重画：更直观（每个都要能一眼认出来）
- [ ] 源码级网：七个按钮各自的 `aria-label` / `aria-haspopup` / `aria-expanded`
- [ ] 变异检验 + 提交

## Task 3: 文本工具（最贵的一件）

**Files:** 判据层 + 镜像 + **九处** + 画布 + 工具栏 + 测试

- [ ] 判据层：`InkText` / `readTexts` / `textBoxOf`（外接框，供选中与渲染）/ `hitTestText` /
      `moveText` / `resizeText`（字号）/ `addText` / `removeText` + `readInkValue` 认 `texts`
- [ ] 用例：`texts` 可选（老值零改动）；坐标与字号两条单位规则；往返
- [ ] **先把两条往返用例改成带 `texts` 的**（`valueFromDraft` / `analysis-payload`）→ 红 → 修
- [ ] 镜像 + 对拍
- [ ] 校验（`findInkValueError`）+ 抽稀（`downsampleInkValue` 不许动 `texts`）
- [ ] **四处渲染**：学生画布（`fillText`）/ 教师 SVG（`<text>`）/ Word（`ink-render.ts` 的 SVG 拼串）/ AI 联系表
- [ ] 画布交互：点一下放文本框（用 HTML `<input>` 浮在画布上）、失焦/回车落定、
      之后能选中/拖动/改字号/删除（复用形状那套选择机制）
- [ ] 工具栏加 `T`
- [ ] 变异检验 + 提交

## Task 4: 真机走查（交给教师）

1. 工具栏一行放得下吗（iPad 竖屏）；三个弹出组好不好点
2. 八色；选中一个图形再点颜色 ⇒ **它变了**
3. 文本：点一下、打字、**键盘有没有盖住正在打的那一行**、落定后能不能拖
4. 提交后去教师抽屉 / 看板 / Word 三处看：**颜色与文字都在**
